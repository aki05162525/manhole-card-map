# 利用者の回答

取り直せない利用者の回答・承認の原文と、その受領の記録を置く。置き場の決まりは [データ保守](../../docs/data-maintenance.md#原本の置き場) にある。AI の調査や分析、スクリプト、画像、他者のサイトの写しは置かない。

- パスは、元の `data/evidence/` の下のパスと同じにしてある。中の記録が指す `data/evidence/` や `data/national/` のファイルと画像は削除してあり、Git の履歴で読める。
- `national/shizuoka-site-tolerance*-20261106/human-answers.json` は、利用者が転記した AI の調査の回答である。電話や現地での確認ではない。
- 中身は書き換えない。受領の記録や台帳の行にある sha256 と照合できなくなる。
