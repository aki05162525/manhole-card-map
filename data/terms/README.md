# 利用条件の写し

法的表示に必要な利用条件・ライセンスの写しと、その取得記録を置く。同じ内容（sha256）のものは1つにまとめる。置き場の決まりは [データ保守](../../docs/data-maintenance.md#原本の置き場) にある。

- パスは、元の `data/evidence/` の下のパスと同じにしてある。中の記録が指す `data/evidence/` のファイルは削除してあり、Git の履歴で読める。
- `rights.json`・`rights-review.json`・`policy.json` は写しではなく、AI が利用条件を点検した記録である。
- 中身は書き換えない。取得記録や台帳の行にある sha256 と照合できなくなる。
