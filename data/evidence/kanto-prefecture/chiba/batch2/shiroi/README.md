# 白井2IDの追加照合

基準確認日2026-11-05を保持し、独立再取得は2026-11-06。旧利用者回答を再質問していない。一般PDF/HTMLはignoredの原本へ取得メタとhashで結び、Gitへ転載しない。

2016設計図9頁・2018完成パンフ8頁・2026年フロア図10頁の概要画像を全頁確認し、設計1/4頁、完成7/8頁、フロア1/5頁を拡大読解した。完成8頁は主棟/東棟と北を配置上で示す。南西保健福祉センターと渡り廊下、南の道路屈曲、東の道路・別棟を数値外形へ対応させた。設計は北が紙面上から約21度右に傾くため図を反時計回りに整列。数値図は北上。面積差は廊下面積の定義も異なるので一致証明には使わない。

本庁舎と東庁舎は数値外形112として連結され、南側は隣接タイル20へ分割される。4タイルを全形描画し、unionは面積比較だけに使用。候補2点は棟側部分の内部点で、タイル境界・取得端・連結部を選んでいない。全棟を一つの重心で代表させず、室内窓口や入口の測量とも主張しない。現カード案内とフロア図は平日東2階/休日本1階守衛室を補強するが、在庫は未確認。

`reproduce-shiroi.py` はリポジトリルートから未使用のignored出力先を渡して実行する。mapbox-vector-tile==2.2.0（依存Shapely）を使用。保存済みrawのhash検証、結合、数値内包と7桁丸め、全体SVGと拡大SVGを再現する。再取得や既存原本の上書きはしない。verification.jsonは今回の限定検証であり、棟同定・CRS・採用承認の代わりではない。国土地理院最適化ベクトルタイルを加工、PDL1.0と原版は県のrights.jsonを継承。
