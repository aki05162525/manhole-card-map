物理5頁は将来の新市庁舎の配置図で、旧本庁舎等の撤去後計画を含む。物理40頁の現況と分けた。設計図は北がページ左上、数値図は北上。2022年記事の小地図は北上。新市庁舎の大きい矩形を水道局として選んでいない。

GSI製品はREADME2026-07-01版、取得世代はtile-inputs.json。中央タイルは以前の保存rawと完全一致。原本取得世代から個別建物の測量年は推定しない。一般タイル仕様と本製品の測地系適用は区別し、製品固有CRSの承認待ちを保持する。rights.jsonでPDL1.0と加工表示を継承しhash照合した。一般HTML/PDFはignored内だけ。

研究資料の視覚確認範囲はcomparison.jsonに記録。107頁設計書は全頁テキスト抽出・ヒット確認、物理5/40頁を画像精読した。他頁の画像精読完了は主張しない。2020年広報は2頁とも画像確認、2022年記事は全1頁確認、2023広報は全2頁テキスト確認と2頁画像確認。旧サービスの敷地内棟名がないことを、旧外形そのものが未収録であることと混同しない。

入口や室内位置は未測量。配布のactive/unknown/ended、在庫、部署継承、建物、位置採用は別々に保持。配布時間質問はhuman-questions.json。原本URL/hash/取得時刻はretrievals.jsonとreuse.json。全既往台帳行・履歴参照はinherited.json、旧値はold-values.json。未着手を資料不足とする行はない。

再現はreproduction.txt、限定検証はverification.json/log。最初の検証用ハーネスは座標適用前の台帳をlifecycleへ渡したため終了1となったが、現assembleの順序に合わせてメモリ上で仮座標/evidenceを適用してから呼ぶよう修正し終了0。台帳ファイルは変更していない。この失敗は製品不具合でなくハーネス入力順序の誤り。アプリコードの変更なし、全suite・UI再検証・コミットなし。
