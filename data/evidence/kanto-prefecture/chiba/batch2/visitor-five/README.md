`*-comparison.json` は施設別の原本読解範囲・方位・年代・周囲との照合・限界を記す。取得済みだが棟に対応できない状況を「未着手」や一括した「資料不足」へ言い換えていない。建物代表点の研究であり入口や室内窓口の測量を条件にしていない。

`inoue/` は市の旧文化財地図の探索点から取得した不一致区域を記録したもの。約1km離れた探索点は不採用。`inoue-corrected-seed/` は県観光案内を探索用として再取得した区域であり、観光案内点そのものは採用していない。

一般HTML/PDF/写真およびそれらの画像化物は `data/work/kanto-prefecture/chiba/next-batch/visitor-five/` に保持した。ここにある原本はGSI数値タイルのみで、BldA/RdCLを面積フィルタなしで図示した。ラベルは見やすさのため面積3000タイル単位より大きい外形に限定するが、図から小建物を削除していない。隣接タイルの重複/端断片は表示を残し、候補にはフルIDを用いた。市川・佐蘭花・旧漉場・たてやまの選択外形はタイル境界非接触。東金の長棟は境界断片を含むので断片ラベルを独立した建物と数えない。

GSI原本の利用条件・版・原取得provenanceはrights.jsonと各tile-inputs/rangesを参照。一般タイル仕様の測地系を本製品の承認根拠にはしていない。小数7桁は演算上の丸めであり、測量精度を表さない。

候補案は `locations-proposed.json` / `lifecycle-proposed.json` / `selection-proposed.json`。approvedは空。旧placeと配布関係の全値/hashはbaselineに保存し、配布関係は変更しない。全国案の適用と独立レビューは県親が担当する。

再現（repoルート）:

```sh
mise exec -- uv run --with mapbox-vector-tile==2.2.0 python data/evidence/kanto-prefecture/chiba/batch2/visitor-five/reproduce.py
```

ネットワーク取得なしで54タイルのhash、decode/combine、全外形SVG、探索focus SVG、東金の東側拡大SVG、4点の丸め後厳密内包、旧値・ID・binding・snapshot hashを検査する。出力先はignoredのdata/work配下のみ許可する。全suiteやUI検証は子では実施せず県親の統合検証に委ねる。テスト成功は原本同定の承認を意味しない。検証時HEAD・入力hash・実行コマンド・終了コードはverification.jsonとverification.logに保存した。

誤記/資料差異: 市川旧PDF URLは404で現行リンクから別原本を取得。旧井上家の市文化財地図探索点と現施設配置は不一致。旧井上家会議録は2019年度だが開催日は2020-01-31。東金利用者URLの誤転記（みの郷）は親指摘で訂正し失敗履歴を維持。たてやまパンフの2つのURLは同一hash、独立2資料と数えない。共通コードとドキュメントの新たな食い違いは検出していない。
