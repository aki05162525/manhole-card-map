## 利用条件と数値

出典：国土交通省「国土数値情報 市町村役場等及び公的集会施設データ」P05-22（2022年4月基準）、https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P05-v3_0.html を加工して作成。加工はレコード抽出、名称住所による現行建物同定、座標順序の組替え。本追補は国が作成したものではない。

今回取得したP05カタログの個別指定はオープンデータ、国交省サイトの現行一般規約は2026-03-23施行PDL1.0。特定の他データの制限をP05へ広げない。P05はJGD2011/EPSG:6668の原値。WGS84変換済みとは主張しない。元データの作成工程には住所ジオコーディングも含まれるが、製品仕様の位置検査は建物外周内を対象としている。今回の追補が住所ジオコーディングを実行したわけではない。

新発田市の一般著作権案内も取得した。文章・写真等の複製転載に関する一般規定と、市が示す座標事実の抽出を区別する。一般規定を座標事実の使用禁止と解釈して保留せず、候補を提示した。保存原本全体の公開・再許諾を承認する意味ではなく、HTML・写真をPDLで再許諾するものでもない。
