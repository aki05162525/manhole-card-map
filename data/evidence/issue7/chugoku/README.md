`prior-audit.json` は旧理由・旧原本参照と分類、`investigation-audit.json` は全57施設の実施履歴、`coordinate-proof.json` は候補の建物同定理由と補助原本、`p05-selected-records.json` は採る4行の原feature、`p05-search-log.txt` は広めの検索候補（誤一致を含む、採用リストではない）。未調査IDはないが47件は未解決である。旧分類は原典不足29、複数棟15、移転/住所同一性5、旧追加proposal未再調査5、誤施設2、混在記録1。今回読んだ中国地方の旧理由には「室内窓口の精密座標がない」だけを理由に保留した例は見つからなかった。

## 出典条件・座標系

出典：国土交通省「国土数値情報（市町村役場等及び公的集会施設）2022年版」。原ZIPは既存 `data/evidence/issue5/chubu/P05-22_GML.zip` を参照し再取得・大量複製しない。原取得時刻・hashは隣の `.source.json` に記録されている。加工者：本調査AI。国土交通省による作成・承認ではない。

今回使用する2022年個別ページ `data/evidence/national/official-facility-index/p05.html` はコメント外で `オープンデータ（CC_BY_4.0）` を指定し、リンク先の旧政府標準規約準拠版はCC BY 4.0互換を記す。一方、`issue5/chubu/p05-catalog.html` は別URLのv3_0ページで「適用する利用規約に基づく」。現一般規約は2026-03-23施行PDL1.0で個別権利表記への留保がある。別ページ/一般規約を混同して2022年の個別条件を消さない。`reused-resources.json` に参照原本hashを保存した。

P05原GeoJSONはJGD2011/EPSG:6668、配列は経度・緯度。数値の転記のみで投影変換・平均化なし。製品仕様の建物外周内位置検査を参照し、名称住所と現在施設の同定を併用する。2022年以後の建替え不存在を一律に証明したという意味ではない。

自治体・運営者HTML全体にP05のライセンスを適用していない。HTMLは個別の施設位置事実を検証する原本で、サイト全体の無制限な再公開を認める判断ではない。一般的な著作権表記だけを理由に座標事実の利用を一律保留してもいない。新見・米子・円形劇場等について独自の測地系精度や室内・入口精度は主張しない。

