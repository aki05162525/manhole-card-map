## 原本・取得時刻・利用条件

`fetch-*.json` は実取得開始/完了時刻、URL、転送先、応答、bytes、SHA256。失敗は例外文字列を保存。原本がない失敗について原本や取得成功を捏造しない。レスポンスCookieヘッダは保存していない。一部画像はURL hashに`.html`を付けたファイル名だが、バイト列は無変換の画像でありcontentTypeとURLで識別できる。

旧原本はrepo相対パスで参照しコピーしない。P05 ZIPの取得時刻は既存`.source.json`にある `2026-11-05T04:46:10.674180+00:00`。今回の新規ダウンロードではない。ZIP SHA256は `3056d3e0d02248143f1f2c9a5e62fd37717eb761a7257106b5d252415aef4cdc`。他の旧原本の取得時刻は、今回参照したメタデータで不明ならnullとし推測しない。

`rights-review.json` に個別指定と一般サイト方針を分離して保存した。

- **P05**：既存カタログ・規約・仕様書を再読。カタログはオープンデータ、規約はPDL1.0（2026-03-23施行）。P05作成工程に住所ジオコーディングが含まれることを否定しない。仕様書は該当施設建物外周内に点があることを検査対象とする。本調査が住所から生成した点ではない。EPSG:6668/JGD2011の原数値を順序変更するのみでWGS84変換済みとはしない。
- **沼津AED**：データセット個別指定の市オープンデータ利用規約PDFを新規取得。4節は注記以外CC BY4.0。出典と加工を下記に表示。
- **中橋**：高山サイト一般規約は文章・写真等を含む内容の無許諾使用を広く禁止しており、オープンライセンスとは扱わない。今回の候補は公式HTMLが当該建物へ指定する座標事実1組で、サイト本文・写真等の再公開許諾を取得したとの主張ではない。一般規約の記録も親レビューへ渡す。
- **飛騨古川**：市運営サイトの一般ポリシーを取得。対象数値への個別制限は確認できなかった。文章・写真を再許諾する主張はしない。

原本全体の一般公開と、座標事実の利用の可否を同一視しない。原本は依頼に従った監査用保全。HTML系数値の測地系は原本に明記されておらず、Web地図緯度経度として無変換で使用する候補で、測量精度を保証しない。
