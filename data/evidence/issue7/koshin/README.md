# Issue #7 甲信地域の追加調査

固定入力 `data/work/issue7-baseline/{ledger,full,assignments,hashes}.json` の `koshin` 担当43 IDだけを調査した。成果は `data/national/issue7/koshin.json`。**16候補、27残件、exact訂正提案1件**。すべて親の独立レビュー待ち。manifest、固定入力、既存原本、Go/UI、配布状態、旧関係は変更していない。branch操作、commit、push、PR、子起動はしていない。

建物代表点まで確認できれば候補にした。入口・室内・階ごとの位置は求めていない。役場など同じ建物にある平日・休日窓口は同じ点を共有する。既知の移転・別棟・座標競合は個別に扱う。単に2022年の点であることだけを理由に、全施設へ改修履歴不存在の証明を要求しない。

## 今回の実調査と限界

`fetch-records.json`、`fetch-additional.json`、`fetch-focused.json`、`fetch-layouts.json` に86の異なるURLへの実取得を保存（84 HTTP 200、2 HTTP 404）。43施設すべてで新規取得を試みた。公式配布案内は共有URLを一度取得し、対象施設ごとに照合した。日時は実際のUTC取得完了時刻。HTTP 200は建物同定成功を意味しない。404は東御市組織ページの誤ったパスと佐久市旧パスのPDFで、その後、正しい東御市組織ページと佐久市の別の現行案内図を取得した。同じ失敗URLの反復、制限回避はない。

旧 `issue5/chubu.json`、独立レビュー、`location-updates/chubu-east-south.json`、既存配布原本・P05原本を再読した。`classification.json` は43 IDごとの旧理由・旧理由分類・今回の取得記録・個別判断。旧理由の引用と今回の判断は別フィールド。原本が既存の場合はrepo相対パスを参照しコピーしない。`reused-archive.json` のP05取得時刻は元記録の `2026-11-05T04:46:10.674180+00:00` を維持し、今回の取得時刻に置き換えていない。旧配布原本の取得時刻は `reused-sources.json` に既存メタデータから転記し、未知の場合はnullとする。

未調査IDはないが、全市のGIS・PLATEAU・すべての施設台帳を網羅して調べたものではない。残件は `fresh-primary-retrieval-partial-coordinate-investigation` とし、現公式への追加アクセス・旧記録再読までと、建物数値の検証完了を区別した。多くの駅内案内所では建物入居関係は十分確認できたが、駅舎の再利用可能な数値原典が未取得。窓口の精密位置を要求して保留しているわけではない。

- fumotto、ゆきむら夢工房、甲斐市水道事務所、さわやかハット、花咲庁舎、浅科：別棟や隣接施設との対応が残る。
- 大月旧案内所と猿橋大黒屋：今回の観光協会公式フッターは猿橋55大黒屋1階。旧駅前施設の点を流用しない。
- 十三くら・寺子屋：市の追加案内図PDFを画像で読み、764-1と758を区別した。図に印刷されたカードの緯度経度は蓋の数値なので不採用。
- 駒ヶ根・大町・小諸・上諏訪・長野・田中の駅内窓口：建物入居は確認できるが駅舎の数値原典が不足。

利用者の精度判断を追加で求める事項はない。残件に必要なのは公開原典の追加取得・棟対応確認であり、精密な室内位置の承認ではない。

## 訂正と文書・コードの不一致

上山田文化会館の旧独立レビュー `requiredEvidence` についてexact old/newと根拠を1件提案。改修履歴不存在を一律に要求する部分を、今回の建物代表点の基準に合わせて再評価する。旧レビュー本体は変更せず、親独立レビューで採否を決める。

今回の閲覧範囲では文書と実装コードの不一致は見つからなかった。Go `Evidence` は実コード `cmd/builddata/ledger.go` の7フィールドと一致する。fetchedAtは取得記録だけに置き、主evidenceへ混入させていない。
