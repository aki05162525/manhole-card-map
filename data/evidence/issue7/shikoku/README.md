## 原本・利用条件

取得したbytesはSHA256名で保存。`.html` 拡張子はHTML以外のXML/JS/CSVにも使うが、bytesを変換していない。元URLとcontentTypeは取得メタデータに記録。PDFの同名 `.txt` はpdftotextによる派生物であり、EvidenceはPDF原本を参照する。Cookieヘッダは保存していない。

P05個別ページのCC BY 4.0指定を適用する。出典：国土交通省「国土数値情報（市町村役場等及び公的集会施設）2022年版」。対象レコードを抽出してlat/lngに並べ替えた加工物であり、国土交通省の承認を意味しない。個別条件・一般規約は旧保存原本 `data/evidence/issue5/chubu/p05-catalog.html`、`p05-terms.html` および `data/national/issue5/reviews/west-south.json` のlicenseReviewを参照。一般PDLを個別CC BY表記の代わりにしない。

県観光サイト等はP05とは別の出典。今回取得したいよ観ネット・こうち旅ネット・うどん県旅ネット・JAPAN 47 GOの一般利用案内を保存した。いよ観ネット・こうち旅ネットは著作物の無許可転載等を制限し、JAPAN 47 GOもコンテンツ転載を制限している。これを「座標という個別の事実も利用禁止」と読み替えず、候補は施設名・住所との同定に必要な座標事実だけを抽出した。反対に、座標採用を理由として原本全体の再公開許諾を取得したとも主張しない。原本は依頼された検証資料であり、画像・説明文・HTML全体をアプリに配信する実装は含めない。徳島GISの一般案内URL推測は404であり、一般利用条件を確認済みとは記載しない。

## 再現と検証

リポジトリrootで実行：

```sh
python data/evidence/issue7/shikoku/build.py
python data/evidence/issue7/shikoku/verify.py
```

ネット接続なしで保存原本から生成する。`research.py` は最初の取得・P05調査、`additional.py URL...` は追加取得用で、再現検証には再取得不要。取得スクリプトを再実行すると取得メタデータが更新されるため、今回の結果再現はbuild/verifyのみを使う。

検証済み：27/27を各1回分類、担当外IDなし、候補12件の数値原典、参照原本hash、exact old/new、Go Evidenceの7フィールド、固定入力を含む1151ファイルの不変、生成の再現性、追跡済みファイルの変更なし。詳細は `verification.json`。この機械検証は建物同定の独立レビューを代替しない。
