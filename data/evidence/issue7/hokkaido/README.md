## 条件と記録

`policy.json` はP05現行第3.0版カタログ・PDL1.0規約と、北海道ポータル規約・自治体自身の施設一覧を区別する。旧版の個別条件を新しい一般規約で上書きしない。座標事実の利用と、HTML全体・写真・地図画像の再公開許諾も同一視しない。原本は監査用に保存し、候補には出典・加工を記す。

- `research.py`：実取得スクリプト。`fetch-records.json`：UTCの実取得開始時刻、URL、最終URL、HTTP状態、原本hash、Content-Type。Cookieや応答ヘッダ一式は保存していない。
- `originals/`：新取得bytesの原本。初期取得スクリプトはCSVも `.html` 拡張子で保存するためURLとContent-Typeで識別する。PDF・XLSXはそれぞれの拡張子。`texts/` はHTMLの読解補助であり原典ではない。
- `targets.json`：68件の旧理由・旧証拠参照。`additional-targets.json` / `targeted-sources.json`：施設別の追加探索先。URLリストは取得再現用。
- `reused-originals.json`：旧原本参照、hash、分かる範囲の元取得時刻。欠損時刻はnull。
- `p05-extraction.json`：選択候補・競合候補のFeature原値とGeoJSONメンバーhash。`candidate-audit.json`：全件の旧未承認理由分類、新しい試行と結論。
- `build.py`：明示した個別判断から成果を生成する。名称部分一致で自動承認しない。
- `verify.py` / `validation.json`：68 ID完全被覆・重複なし、30座標の数値原典、250原本参照hash、Evidence7フィールド、固定入力と記録済み旧入力の不変を検証。
