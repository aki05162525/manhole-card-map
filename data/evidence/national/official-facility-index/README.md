# 公的施設地点による全国配布施設の補完（2026-11-05）

全国で利用できるデータはある。国土交通省の市町村役場等及び公的集会施設 P05-22 を取得し、全国47都道府県・79,532地点を照合した。原典は2022年4月基準、公開ページの更新履歴は2023年。CC BY 4.0。製品仕様書8章は建物外周内の位置検査を定めているため、住所代表点を既存ジオコーダーから転用する手法ではない。ただし2022年以後の移転・建替え、同一番地の別棟を自動解決できない。

出典：[国土数値情報P05](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P05-2022.html)、[製品仕様書](https://nlftp.mlit.go.jp/ksj/gml/product_spec/KS-PS-P05-v3_0_1.pdf)。他データの仕様・利用条件・採否は `sources.json`、取得原本のURL・時刻・SHA-256・バイト数は各 `*.source.json` に記録した。

## 成果と適用見込み

入力の全国full.jsonと完成済み地域override/reportを取り込み、legacyIdsを施設IDへ置き換えて重複を除いた。施設1,651件、位置未確定1,503件。地域overrideのcoordinateはstatusを持たずlat/lngだけの場合があるため、数値座標が既にある148施設は対象外とした。

249施設・258組に候補があり、このうち242施設は番地まで正規化一致した。3施設を現行公式案内と手動照合し、`updates`に移した。残り246施設は`candidates`。約1,500件すべてを埋めるデータではなく、まず242施設を優先レビューするための実測された候補集合である。242件は新規確定数でも成功率予測でもない。台帳の古い窓口・休止/終了関係も含み得るため、現行配布先確認で減る。全国候補をすべて人手相当で検証したわけではない。

実値検証済みの更新は次の3件。生のGeoJSON Feature、ZIP内locator、メンバーhash、現行公式ページ、レビュー理由を結果JSONに添付している。

- 水戸芸術館：緯度36.38038497383131、経度140.46578600462854。現行市公式配布先は芸術館内アートショップコントルポアン。施設アクセスと市配布ページが五軒町1-6-8で一致。市ページ更新2026-05-29。
- 日立市役所下水道課：緯度36.59915666235926、経度140.64821195109542。市公式配布ページに本庁舎6階・助川町1-1-1。休日の別配布先には適用しない。ページ更新2024-04-10、2026-11-05時点の現行公開内容を取得。
- 土浦市立一中地区公民館：緯度36.082820759533234、経度140.19493317655983。市施設ページ（更新2026-10-15）と現行配布一覧PDFが大手町13-9で一致。公式ページのmeta refresh先も保存した。

これらは施設の建物代表点であり、窓口・入口・階内位置の実測ではない。2022年データだけで確定していない。現行ページに移転案内はないが、同一住所での建替えがないことまで保証しない。

## 取得・照合と再現

依存はPython 3標準ライブラリと `pdftotext`。ネットワーク取得はurllib。拒否やTLS失敗を回避する設定は使わない。既存取得hashと違うbytesを再取得したら停止する。

```sh
python data/evidence/national/official-facility-index/reproduce.py
```

これは取得済み原本をhash検証し、`data/work/official-facility-index/inputs/` の固定入力から候補を再生成し、`reviews.json`に明記した3件だけを昇格し、テストする。入力ファイル一覧・hashは `input-manifest.json`。work内の固定入力と大きな原本も親エージェントが保全すること。リポジトリ内の入力が更新された状態で固定入力がない場合、同一結果の再現を主張してはいけない。

最新台帳で再照合する場合は `build.py`（`--frozen`なし）で固定入力を更新し、その後 `approve.py`、`test_index.py`。レビュー済み施設がなくなった・住所や元地点が変わった場合は昇格処理を失敗させて再レビューする。`reproduce.py`はレビュー済みページ原本がないとき再取得するが、サイト内容が変わっていたら停止し、以前のhashを書き換えない。

- `fetch.py`：公開原本保存と取得メタデータ。
- `build.py`：全国ZIP内47県GeoJSONと八王子CSVを読み、入力台帳に照合。住所はNFKC、都道府県接頭辞、算用数字の丁目・番・号表記、括弧内方書だけを正規化。数字の番地を落とさない。漢数字丁目や括弧外の階/建物名は保守的に不一致にする。
- 完全名称一致＋同市区町村で住所不一致もランキングに残す。部分名称一致は完全住所一致時だけ。fuzzy距離は使わない。100点＝名前・住所一致、90点＝名前包含・住所一致、65点＝同名・住所不一致。点数から自動昇格しない。
- `approve.py`：手動レビュー対象と生原本のhash・本文・名前・住所一致を検査し、更新形式へ出力。採用済み候補はupdates内のcandidateに保存し、未採用candidatesと分離。
- `test_index.py`：同名別自治体、異なる番地、あいまい名称を通さないこと、既存確定点を除くこと、採用3点のGeoJSON原本・GML軸順・全証拠hashを検証する。

結果の書き込み先は `data/national/location-updates/official-facility-index.json` のみ。元台帳・地域ファイル・Go/UIは変更していない。commit/push/PRも行っていない。

## 他データと誤用防止

P02公共施設（2006）、P27文化施設（2013）、P28国・都道府県機関（2022）の公式仕様も保存した。いずれもページに非商用とあるため、P05と同じCC BYとして汎用台帳に混ぜない。前二者は古さも大きい。バイナリ本体は取得していない。

デジタル庁の自治体標準オープンデータセットは共通項目定義であり、全国の施設地点をまとめたファイルではない。八王子市の正式CSVを取得し609地点を実際に照合したが、今回の未確定施設に名称＋住所の一致は0件だった。同名「郷土資料館」の別自治体は除外した。CSVの緯度経度欄だけでは測地系や建物点の定義が確認できないため、ヒットしても即採用しない。市の現行カードページでは駅前インフォメーションセンターを配布場所としており、公共施設CSVが民間・観光窓口まで網羅する保証はない。

北海道施設位置情報DBも公式カタログを調べた。本文では2010～2015年の国土数値情報と市町村データを混載し、古い/現存しない施設があると注意している。閲覧日のカタログ更新日時を個々の地点の更新日と誤認しない。原典ごとのライセンス・測地系の確認が必要なため、本体を一律採用せず全国の新しいP05を優先した。

同じ番地の牛久市役所と分庁舎、守谷市役所と守衛室などに複数の候補地点がある。住所一致・名前包含だけで建物を決めない。下妻市立図書館は台帳の「砂沼新田」とP05の「砂沼神田」が不一致であり、勝手に訂正しない。

## 座標系・原本の問題

P05のGeoJSONは明示的にEPSG:6668（JGD2011）、配列は経度・緯度。GMLは緯度・経度。データをWeb Mercatorや平面直角から変換していない。lat/lngに順番を正して元数値を保持する。GSIマップシートFAQおよび国土交通省参照系仕様の実用上の世界測地系同等性に基づく地図表示用途であり、地殻変動・観測epochの補正やセンチメートル精度を主張しない。出典測地系は更新のdatasetEvidenceに残す。旧Tokyo Datum/JGD2000をこの処理へ入れない。

座標系の根拠は `gsi-mapsheet-faq.html` と `crs-excerpt.txt`（元PDFのSHA-256付き）。GSI本体datum-mainはTLSのlegacy renegotiationエラーとなったため安全設定を緩めず記録した。独立した公開FAQと国交省公式仕様を取得した。

P05茨城GMLには `<ksj:publicOfficeClassification public office>` というXMLとして不正なタグがあり、全文XML parserが失敗する。`source-gml-issue.txt` に原本行を保存。原本は改変せず正常なGeoJSONを主データとして使う。テストではGMLのPoint要素だけを個別に読み軸順を照合する。製品の論理一貫性「誤率0%」という説明と配布XMLの実体が一致しない点であり、利用上の制約として報告する。

既存リポジトリの説明とコードの矛盾はこの作業では見つけていない。地域overrideとfull.jsonの座標schema差はコードの実データに合わせて処理した。
