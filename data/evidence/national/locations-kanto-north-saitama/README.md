## 根拠と精度

県の施設情報、県公式「パパ・ママ応援ショップ」施設検索、県物産観光協会の観光施設情報、市町の公式施設アクセスを参照した。元監査に保存済みの配布記事・アクセス原本は再取得せず再利用した。新規取得はホストごとに約1秒以上の間隔を置いた。403/TLSの回避はしていない。深谷テラスパークと石井水処理センターの公式短縮地図リンクは429で停止した。

採用する値はq/destination、明示Marker.position、Google Mapsのplaceまたは経路到着点。埋込地図pbのviewport、@中心、ll、GIS初期中心、住所ジオコード、マンホール蓋位置は使っていない。建物代表点・公式施設代表点であり、室内窓口精度ではない。特に守衛室別棟、公園内の店舗別棟、庁舎別館は同じ住所だけでは結び付けていない。

下水道公社5支社は県公式施設情報の水循環センターと支社の管理先・所在地を公社原本に照合した施設代表点。荒川水循環センター守衛室にはこの点を流用しない。戸田新曽南庁舎・戸田公園駅前行政センター・キュポ・ラは、同じ建物の別階施設の明示点を建物代表点として使用している。新しい村は町の配布記事13667が「森の市場 結」と明記しており、その施設のMarkerを採用した。

すべて **AIによる原典照合**。現地確認・人による確認とは扱わない。親担当の検証・統合用追補であり、元データを直接更新していない。

## 保存と取得時刻の制約

`manifest.json` にURL、原本パス、SHA-256、取得記録を保存。既存原本のコピーには `reusedFrom` を記録した。URLからSHA-256先頭20桁を使ったファイル名は、内容ハッシュそのものではない。内容の検証にはmanifestの `snapshotSHA256` を使う。

初期の複数取得処理が古いmanifestを上書きしたため、24原本の取得開始時刻・HTTPメタデータが欠けた。保存済みbytesとURLをinspection記録から復元し、`fetchedAt: null`、実ファイル保存時刻 `snapshotSavedAt`、`provenanceNote` を明示した。時刻を捏造せず原本も再取得していない。55更新中15更新の主根拠がこの復元記録に該当する。`checkedAt` はAI照合時刻であり取得時刻ではない。この取得メタデータの制約は親担当で統合時に判断すること。

元GKP現行一覧の取得日は11月5日で秒単位未記録。今回の座標主根拠にはGKP原本を使っていない。既存施設のID/name/addressを同定の起点として維持した。

## 再現と検証

リポジトリルートから実行（build/validateはネットワークアクセスしない）:

```sh
uv run --with requests --with beautifulsoup4 python data/evidence/national/locations-kanto-north-saitama/build.py
uv run --with requests --with beautifulsoup4 python data/evidence/national/locations-kanto-north-saitama/validate.py
```

`validation.json`: 全84件の網羅、一意ID、元fragment参照、採用座標の原文値、全manifest原本SHA-256を検査済み。施設同定の判断は `decisions.json` と保存原本で再審査可能。これらの検査は地理的な実測や現地確認の代わりではない。

`research.py` / `batch.py` / `directory.py` / `scan.py` は調査・保存用。`report.py` は県一覧Markerと住所の表示、`reconcile_manifest.py` は欠損取得記録の復元手順。`cache-scan.txt`、`*.inspection.txt` は原本の派生抽出で、証拠bytesの代替ではない。`directory-results.json` は各施設の県施設検索の結果。
