## 根拠と再現

`manifest.json`は実取得URL、取得開始日時（UTC）、HTTP結果、最終URL、原本パス、SHA256を記録する。HTMLはresponse bytesを保存し、既存`.gitattributes`の`data/evidence/**/*.html -text`対象。改行を正規化しない。

`decisions.json`はカード別のAI照合判断、`place-corrections.json`は根拠を得た住所等の修正、`coordinates.json`は明示的に選んだ目的地座標とlocator。`address-sources.json`は追加施設案内のカード対応。これらが再生成用の確定入力であり、自動キーワード判定で承認したものではない。住所照合は表記差を正規化するが、座標を住所から生成しない。

リポジトリrootで実行：

```sh
python data/evidence/national/north/build_fragment.py
python data/evidence/national/north/verify.py
```

`collect.py`はURLリストを渡して取得可能。同じURLはmanifestキャッシュを再利用し、同一ホスト約1.1秒間隔。アクセス制限を回避する処理はない。`read_sources.py`は原本から読むための補助。review-*.txtは初回の読解用派生資料で、承認根拠は原本と最終decisionsにある。

`gkp-comparison.json`は統合担当提供の`/tmp/gkp-current-design.html`と抽出JSONによる全204カードの比較記録。配布場所原文の差分は0件。地域班はGKP全件HTMLを新規取得していない。GKP原本の正式保存先と実取得時刻は統合担当のmanifestへ帰属させること。この比較記録を単独の承認根拠にはしていない。

`validation.json`に最終件数と不変入力3ファイルのSHA256を保存した。検証は全カード・全入力関係のカバレッジ、施設ID・alias・関係の重複、孤立施設、不変sourceHash、全snapshot SHA256、Evidenceの実取得原本対応、座標のq/目的地リテラルを確認する。フルビルド・共有台帳への統合は親担当に委ねる。
