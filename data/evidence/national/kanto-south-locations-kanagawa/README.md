# 南関東追補：神奈川県の配布施設座標

対象は元の南関東台帳で cardId が `14` から始まるカードに結び付く、座標未確定の46施設。33施設を追加確定し、13施設を未解決として残した。同じ建物の別窓口は施設IDごとに出力するが、原典取得・建物調査は共有している。全国整備完了を示す成果ではない。

成果は `data/national/location-updates/kanto-south-kanagawa.json`。元台帳・地域JSONには反映していない。名称・住所・配布窓口と公開地点をAIが照合したもので、現地確認・人による確認や室内窓口の測量ではない。

## 原典と採否

- 自治体の数値目的地リンク、自治体公開CSV、施設運営者の地図リンク、国土交通省の施設GIS、日本観光振興協会の全国観光情報DBを使用した。各地点の原典と抽出箇所はパッチ内の evidence に記載している。
- Google Maps は数値 `q`、施設レコードのマーカー、短縮リンク先の地点 feature を確認した。`ll`、`@`、埋込の viewport 中心、住所文字列のみの検索位置は採用していない。公式ページから埋込への関係は manifest の `linkedFrom` に記録した。
- 国土数値情報 P05 は2022年の公開施設Point。名称・住所を現行施設案内と照合した。公式整備方法は住所による初期位置取得後に地図で施設位置を確認するもので、今回新規に住所ジオコードを実行したものではない。公開施設地点の精度に限り、室内や入口の精密位置とは扱わない。
- 全国観光情報DBは名称・住所を自治体や地元運営者の案内と照合した。古い住所の横浜駅案内所レコードは不採用。営業時間などは本調査の採用対象ではない。
- 同番地の別棟、役場本館と別館、公園と博物館などを区別した。PDF略図から数値座標を推定していない。

## 未解決と移転確認

13施設それぞれの実調査URL・結果・保留理由はパッチの unresolved と `review.json` に記録した。主な制約は、公式サイトのHTTP403・307チャレンジ、地図短縮リンクのHTTP429、公開CSVの座標空欄、対象建物を特定できない地図、旧住所と現住所の不一致。アクセス制限を回避していない。

三浦市役所第2分館は、元の配布案内と公式の2026年4月移転計画に確認課題がある。`proposals.json` に移転確認依頼を1件記録した。移転の実施と新しい配布窓口を確認できていないため、移転先の承認や旧施設の座標上書きはしていない。

## ファイルと検証

- `manifest.json`: 144取得記録、うち140件に原本スナップショット・SHA256あり。取得失敗も記録。既存キャッシュは再取得せず参照したため、一部snapshotPathは元の `kanto-south/` 配下を指す。取得日時は各記録の fetchedAt。
- `targets.json`: 担当46施設の元台帳抜粋。
- `review.json`: 全46施設の採否と照合した原典の一覧。
- `decisions.py` / `attempts.py`: 採用地点と施設ごとの調査先・保留理由。
- `validation.json`: 全46施設の過不足・重複なし、既存施設ID参照、全原本ハッシュ、採用数値と原典レコードの一致を確認した結果。

リポジトリルートから以下を実行すると、保存済み原本のみで再生成・検証できる。

```sh
python data/evidence/national/kanto-south-locations-kanagawa/build_patch.py
python data/evidence/national/kanto-south-locations-kanagawa/validate.py
```

build時の checkedAt はAIによる再照合日であり、原本の取得日や現地確認日ではない。取得日を比較する際は manifest の fetchedAt を用いる。新規取得では同一ホストへの間隔を約1秒以上空け、既取得URLをキャッシュ再利用した。
