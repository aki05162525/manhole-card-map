豊島区庁舎への交通アクセス

区役所の開庁時間と受付時間（必ずご確認ください）

区役所の開庁時間と受付時間は異なりますので、お越しの際はこちらから開庁時間と受付時間をご確認のうえ、お越しくださいますようお願いします。

利用方法

『駅・停留所を選択』メニューで、豊島区役所に向かう際の出発点を選択したら、表示ボタンをクリックしてください。

なお、池袋駅、東池袋駅からは音声による道案内があります。ご利用の方は、こちら（新しいウィンドウで開きます）をクリックしてください。（外部リンク「認定NPO法人　ことばの道案内」のページにつながります）

表示

池袋東口からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

池袋駅方面から来庁する場合は、東口を出て、グリーン大通りを進みます。

しばらくグリーン大通りをまっすぐ進みます。

右手のガソリンスタンドの先を右手に曲がってください。間もなく豊島区役所の北側入口が見えてきます。

東池袋駅からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

東池袋駅で降車したら、1番出口に向かってください。

突き当りを左に曲がると地下2階につながる地下通路があります。

地下2階からはエレベータかエスカレータで上ってください。エスカレータの場合は、マンションの入口に進んでしまわないようご注意ください。

東池袋1丁目バス停からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

東池袋1丁目バス停を降車したら、池袋駅とは反対方向に進んでください。

右手のガソリンスタンドの先を右手に曲がってください。間もなく豊島区役所の入口が見えてきます。

豊島区役所バス停からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

バスを降車したら、高架下沿いに歩道を進みます。

自転車置き場の手前を、左前方へ進むと、豊島区役所が見えてきます。

都電東池袋4丁目駅からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

都電を降車したら、高架下沿いに歩道をしばらく進みます。

自転車置き場の手前を、左前方へ進むと、豊島区役所が見えてきます。

都電雑司ヶ谷駅からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

都電を降車したら、奥にコンビニエンスストアの見える方向に進みます。

コンビニエンスストアの角を右に曲がります。すると前方に豊島区役所が見えてきます。

豊島区役所は南側または東側のどちらからでも入ることができます。

ビックリガードからの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

東通りに入り、しばらく進みます。

しばらく進むと、右手に南池袋小学校が見え、左手に茶色い建物が見えてきます。

茶色い建物の先の道を左に曲がります。すると正面に豊島区役所の建物が見えてきます。

旧区役所からの経路

  1. 「東池袋1丁目」バス停・都バス「都 02 乙系統」・「草 63-2 系統」
  2. 「豊島区役所」バス停・国際興業バス「池 07 系統」
  3. 「東池袋駅」・東京メトロ有楽町線（駅～庁舎間地下通路）
  4. 「東池袋四丁目」・都電荒川線
  5. 「都電雑司ヶ谷」・都電荒川線

池袋駅から見て、旧区役所の手前の道を右に曲がり、しばらく進みます。

グリーン大通りまで出たら、大通りを横断し、左に進みます。

右手のガソリンスタンドの先を右手に曲がってください。間もなく豊島区役所の入口が見えてきます。

  • 東池袋駅（東京メトロ有楽町線）…地下通路で直結（改札から徒歩3分・1番口方面）
  • 都電雑司ヶ谷駅（都電荒川線）…徒歩3分

有楽町線・東池袋駅からの経路

有楽町線東池袋駅からは、エスカレーターまたはエレベーターで1階までお越しいただけます。
各種お手続きのため窓口へ向かわれる方は1階のエレベーターホールもしくはエスカレータ（3・4階まで）をご利用ください。
