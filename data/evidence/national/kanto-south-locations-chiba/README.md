# 千葉県カードの配布施設位置追補

対象は cardId 先頭12に結び付く既存地域fragmentの未位置48施設。AIによる公開資料の照合であり、人・現地確認ではない。元台帳・地域JSON・他担当ファイル・Go/UIは変更していない。commit/branch/push/PR操作なし。

成果：`data/national/location-updates/kanto-south-chiba.json`。40施設に公開目的地点を追加提案、8施設は未解決。40件の内訳は **建物代表点35、施設代表点5**。施設代表点5（観賞植物園、渚の駅たてやま、みのりの郷東金、旧井上家住宅、風和里しばやま）は園・複合施設等の公式公開地点であり、敷地内の受付棟や室内カウンターの位置まで確定したものではない。親の採否判断でbuildingだけを採用する場合は追加35・未解決13として扱うこと。施設代表点をbuildingへ変更しない。

## 原典と再現

- manifestは128 URL。HTTP200=125、404=2、TLS hostname mismatch=1。38 URLは元担当キャッシュをコピーして再利用し、取得日時・SHAを引き継いだ。新規取得は90 URL。原本bytesを拡張子に関わらず `.html` へ保存している（PDF/CSV/XML/JSもある）。`.txt`・`.log`は派生物。
- `manifest.json`にURL、実取得日時（UTC）、HTTP状態、最終URL、保存先、SHA256を記録。再利用には`reusedFrom`。失敗したTLS取得は原本なし。アクセス制限回避・TLS検証無効化なし。
- 同一施設のカード違いは重複調査しない。野田市役所、長生村役場など同一建物内の別窓口はIDを維持して位置だけ共有する。八街・白井・袖ケ浦・習志野の複数棟は代表点を流用しない。
- `research.py` は既存キャッシュ優先、ネット取得前に1.1秒待機。`batch*.py`、`final_followup.py`は調査の再実行用で、同一URLを再取得しない。
- `decisions.py` はAIが照合した採用座標・選択理由。`build.py` はオフラインでパッチを再生成。`facilities-reviewed.json` は全48施設のID・名称・住所・採否。`targets.json` は追加取得対象の対応表。
- 再生成：`uv run --with requests --with beautifulsoup4 python data/evidence/national/kanto-south-locations-chiba/build.py`
- 検証：`python data/evidence/national/kanto-south-locations-chiba/validate.py`。全48件のID参照、重複なし、updates/unresolvedの完全分割、全保存原本SHA、座標数値の同一原典レコード内の共起、CSV行・施設マーカー属性、未解決の実取得URLを確認済み。Google embedは`initEmbed`の施設entity名・住所・座標を選び、viewport値を取っていない。

## 原典の注意点・棄却した値

1. 市川市行徳図書館の施設ページは行徳支所を地図マーカーにしている。市の2026年4月公共施設CSVで、行徳図書館自身の行・住所・座標を照合した。中央図書館、観賞植物園も同CSVを採用。
2. いちかわ観光物産インフォメーションは旧八幡市民談話室1階。現行住所だけで同一建物と推測せず、市の移転発表PDF p1（2021-03-23）とCSVの建物名・住所を突合した。今回新たな移転proposalはない。
3. 館山市のカードページの三つの地図は蓋設置位置。すべて施設位置の根拠から除外。県観光特集は東口案内所の節の住所括弧を「西口」と記載する食い違いがある。市の配布本文の「東口」と県の独立した東口マーカー名を照合し、西口マーカーとは区別した。西口は観光協会レンタサイクル案内・西口案内所ページも確認。
4. 関宿城博物館の公式アクセス本文の旧mapリンクは36.1002253,139.7822838、下部の住所付きmapリンクは36.1005348,139.7827015。今回は住所付き施設リンクを採用し、相違をsourceLocatorにも明記。
5. 鎌ケ谷の施設ページURLのlat/lngは地図表示中心。市公式localmap.jsが施設XMLのData/Positionでマーカー生成することを確認し、XMLの市役所・郷土資料館それぞれの名称と住所に結び付く値を採用した。URL中心値は不採用。
6. 長生村アクセスガイドの地図は村全体。役場として不採用。公式施設マップXMLの長生村役場レコードで確認し、同住所の保健センターとは別地点とした。
7. 県の観光案内所特集には船橋市観光協会の旧施設位置が残っている。船橋にはこれを使用せず、現行ららテラスTOKYO-BAYの公式施設マーカーと市の現行配布住所を照合した。

## 未解決8施設

- 佐蘭花：公園全体のリンクから管理棟を特定できない。
- 習志野企業局新館3階：全体の目的地は取得したが本館・新館・別館の区別が不足。現行公式の局舎更新計画も複数棟を明示。将来の建替え先に旧窓口を移さない。
- 柏市上下水道局：住所・3階総務課は確認。公式PDFは模式案内図で数値位置なし。建替え前の地点は転用しない。
- 袖ケ浦終末処理場管理棟2階：現行公式事務室案内の位置は画像。追加検索で見つかった配置図PDFはHTTP404。管理棟の数値地点未確認。
- 袖ケ浦南庁舎守衛室：市アクセスとそでMAP入口を取得したが、南庁舎の独立した公開数値地点は得られない。
- 八街第一庁舎受付：市役所全体マーカーと第一庁舎の同定不足。第三庁舎の独立マーカーとは分離。
- 白井東庁舎上下水道課、本庁舎守衛室：現行公共施設CSVは「本庁舎・東庁舎」を一地点にまとめている。公式フロアマップで窓口の棟は確認したが、棟別数値位置はない。

未解決には施設別に実調査URLと結果・理由を格納した。外部制約は施設別数値データの不足、統合された複数棟の公開点、404（旧配置図・旧施設リンク）、科学館旧www2ホストのTLS証明書不一致。科学館は別の県公式施設詳細で位置を解決した。

ドキュメントと既存コードの書き方の不一致は、この調査範囲では発見していない。上記は公開資料相互・地図対象の食い違いであり、コード仕様を変更するものではない。
