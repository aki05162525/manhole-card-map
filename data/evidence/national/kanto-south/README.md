## ファイルと再現

- `data/overrides/regions/kanto-south.json`：PlaceLedger schema 1の採用用fragment。
- `data/national/regions/kanto-south.json`：全カード・全元関係の監査。実取得URLと結果、採否、座標・配布条件の残課題、proposalを収録。
- このディレクトリの`manifest.json`とURLハッシュ名`.html`：実際に受信した原本bytesとSHA256、取得開始時刻（UTC）、リダイレクト先、HTTP結果。`.txt`は確認用の派生テキストで、原典ハッシュの対象ではない。
- `decisions.py`：AIが読んだ配布案内の手動転記。`coordinates.py`：公式目的地座標の手動判定。`unresolved.py`：未確定カードの個別理由。
- `build.py`は上記を不変入力に適用しfragment/監査をオフライン再生成する。`validate.py`は全件網羅、重複・孤立、原本hash、sourceHash、座標の原本内q/destination一致を検証する。
- `research.py`・`fetch_more.py`は取得済みURLを再利用し、同一ホストに約1秒以上間隔を置く。アクセス拒否回避やTLS検証無効化は行っていない。`extra.py`は追加リンク探索用。HTML改行は既存`.gitattributes`の`-text`で維持。

再現：`python data/evidence/national/kanto-south/build.py`、`python data/evidence/national/kanto-south/validate.py`。
実コードの検証：`go run ./cmd/builddata -places data/overrides/regions/kanto-south.json -out data/evidence/national/kanto-south/validation-build -as-of 2026-11-05`も成功（1313カード、1725関係、配布ピン29）。検証生成物は重複・容量を避けるため保存しない。
