# 中国・四国 配布施設の位置追補

2026-11-05調査。対象は地域fragmentの181施設のうち、既存座標11施設を除く未位置170施設。追加101、未解決69。全facilityIdを重複なく一方へ割り当てた。元fragment・元監査・台帳・アプリは変更していない。

成果は `data/national/location-updates/chugoku-shikoku.json`。親担当による根拠レビュー後の統合用であり、配布関係の新規確定や移転proposal採用は行っていない。

## 根拠と再検証

- `facility-audit.json`: 全170施設の名称、現台帳住所、legacyPlaceIds、判断、取得原典への参照。
- `reused-manifest.json`: 採用・保留の照合に使った304 URLレコード。303原本と取得失敗1件。URL、実取得日時、SHA256を保持。既存キャッシュからコピーしたものは`reusedFrom`を記録し、取得日時を今回の日付へ書き換えていない。
- `manifest.json`: 今回取得した補助原典。非200レスポンスもそのまま保管。TLSエラーを回避していない。
- `targets.json`, `sources.json`, `decisions.json`: 調査対象、施設別の補助URL、座標決定の再現用データ。
- `validation.json`: 全対象割当、原本ハッシュ、全101座標の原典値との一致、P05の32レコードをZIPから再読込した比較結果。
- 再検証: `python data/evidence/national/locations-chugoku-shikoku/validate.py`（ネットワーク不要）。数値一致検査に加え、施設名・所在地・地図内の地点の役割は調査時にAIが確認した。機械検査が意味の同一性を証明するものではない。

採用は公式施設情報のq/query/daddr、JSON-LD GeoCoordinates、施設名付きマーカー、位置メタデータ、および国土交通省の公共施設地点データ。表示中心や住所ジオコーディングは採用していない。すべて施設・建物代表点であり、階・室内窓口の精密位置ではない。複数窓口が同じ建物点を共有する場合もfacilityIdは統合していない。

## 国土数値情報の出典

出典: 国土交通省「国土数値情報（市町村役場等及び公的集会施設データ）P05-2022」。元ZIP、製品仕様、利用条件、分類表も既取得原本を再利用して保存した。CC BY 4.0の条件に従い出典を表示する。元データのJGD2011の緯度経度を保持し、測量・精度改善は行っていない。原典の名称と所在地を現在の公式案内に突合した32施設だけを採用した。抽出は加工に当たり、国土交通省がこの成果を承認したことを意味しない。

2022年基準データだけでは移転を判定できないため、西ノ島町役場、多度津町役場、長船支所などは保留。丸亀市役所の旧大手町2-3-1レコードは不採用とし、現大手町2-4-21の市公式施設マーカーを別途採用した。
