# chubu-east 北部 位置追補（15–18）

2026-11-05。新潟・富山・石川・福井の既存 canonical 未位置施設88件を全件調査し、63件の建物・施設代表点を追加候補とした。残る25件には施設別の実調査URLと未解決理由を付けた。室内の窓口・階の正確な位置を測定したものではない。配布関係・移転proposalの採否は変更しない。

成果は `data/national/location-updates/chubu-east-north.json`。`pending-candidates.json` はcanonical施設のない2関係を別扱いにし、蔵春閣の位置候補1件を記録した。配布未確認関係はpendingのまま。

## 検証と保存

- `manifest.json`: 原本bytesのパス、SHA256、URL SHA256、HTTP結果、実取得日時。キャッシュ再利用は `reusedFrom` と元取得日時を維持。取得失敗も記録。拡張子htmlでもcontentTypeがCSV・JSON・JS・XLSXの場合がある。
- `facility-audit.json`: 88施設の名称・住所・採否と調べた原本への参照。
- `evidence-chains.json`: 採用63施設の数値原典と公式掲載元。Google短縮URLは公式ページに実在するリンクだけを展開して採用。`/@` 表示中心は採用していない。
- `decisions.json`: 数値・原典内locatorと照合理由。`research-index.json` と `*-results.json` は追加調査履歴。第三者サイトや別施設ページが探索中に含まれる場合も、採用根拠とはしていない。
- `validation.json`: 88件の対象一致、重複なし、既位置施設の更新なし、原本hash/size、全座標数値の原本存在、公式元ページと短縮リンクの対応、未解決URLのmanifest対応を検査済み。
- 再検査: `python data/evidence/national/locations-chubu-east-north/validate.py`。包装再生成: 同dirの `package.py`（ネットワークなし）。原典の数値存在チェックは施設同一性の人間判断を代替しないため、親担当で採否レビューする。

読み取った範囲でドキュメントと既存コードの食い違いは発見していない。元地域fragment・元台帳・Go/UIは編集していない。commit/branch/push/PR操作なし。

## 根拠のつながりと注意点

- 富山市の公式配布ページにある `markers[0..9]` は名称付きの個別施設点。地図全体の `points` 中心とは別である。該当する未位置7施設を採用。
- 佐渡市の公開案内 `https://www.city.sado.niigata.jp/soshiki/2002/30816.html` → `opendata-sado-city.hub.arcgis.com` → ArcGIS組織 `CkpxhGWnBSk5Y9fW` の施設GIS。geometryは `outSR=4326` 指定。旧行政サービスセンター名称は現市民センター住所・電話一覧 `.../soshiki/2028/55004.html` で照合。佐和田市民センターと中央会館は同住所なのにGIS点が約500m異なり、ともに不採用。
- 三条市DX推進課の公開データ案内 `.../dxsuishinka/service/4773.html` → `material/files/group/3/000104488.csv` のNO19中央公民館・NO75下水処理センターを現施設名・住所と照合。
- 穴水町役場の `initlat/initlong` は参照JS `shisetsu-detail-googlemap.js` が実際に `google.maps.Marker(position:myLatlng)` に渡す。単なる中心値として採用したものではない。
- きらりうむ佐渡は台帳「18」に対し公式詳細「18番地1」。施設名・市公式へのリンクを突合し同施設と判断した。住所の書き換えはしない。
- イカの駅は公式アクセス本文が台帳と同じ「越坂18字18番1」。公式リンク先の同名place IDは `0x50624158121f0471`。ルート文字列には「18字6番1」もあり、この表記差を留保として残す。数値は公式掲載短縮リンクの施設featureを採用。
- まつだいふるさと会館は県観光の同名施設JSON-LDを採用。カードページ末尾の無記名qは採用しない。
- 能登ワインは台帳「リ5番6」と県観光「リ5番1」の違いが未解消で不採用。道の駅朝日の物産会館（猿沢1215）と駅全体（1212）、射水の物産館と駅全体、清津峡Periscopeとトンネル、公園管理事務所と公園全体も区別した。
- ながおか市民センターの旧施設点へ後継アオーレ点は付けない。朝日みどりの里再整備、ながおか市民センター配布終了等は原監査・移転担当で確認する事項で、この成果で配布関係を変更しない。

## 未解決25施設

実際に確認したURLと原本は成果JSONのattemptsおよびfacility-audit.jsonに記録。

- **福井市一乗谷朝倉氏遺跡復原町並**: 保存協会アクセスと福井市観光の復原町並を調査。観光JSON-LDは町並全体の地点で、台帳の復原町並受付（城戸ノ内町28-43）に対応する建物・入口地点を分離できない。広い史跡の代表点を受付点として採用しない。
- **舟橋会館 事務室窓口**: 舟橋村公式会館詳細で海老江147を確認。埋込地図は住所ラベルとviewportのみで、会館建物の数値markerを確定できない。中新川広域組合トップのGoogleリンクは国重242の別庁舎で不採用。
- **燕市役所 2階 下水道課**: 燕市公式市役所案内・アクセス・公開データを調査。吉田西太田1934の庁舎住所は一致するが、掲載案内図・施設地図入口から庁舎の明示数値markerを得られず、2階下水道課の目的地座標は未確定。
- **道の駅朝日 朝日みどりの里物産会館**: 朝日みどりの里公式の物産会館・配置案内と県観光の道の駅を照合。物産会館は猿沢1215、県観光の道の駅は猿沢1212で複数棟構成。道の駅全体点を物産会館へ流用しない。再整備の記載は別途注意事項。
- **かほく市産業建設部 上下水道課**: かほく市公式配布案内と観光公式アクセスを調査。対象は市役所宇野気ニ81の上下水道課。観光アクセスは地域案内または高松の観光協会であり当該庁舎の明示数値markerを確認できない。
- **燕市役所 1階 夜間休日受付**: 燕市公式市役所案内・アクセス・公開データを調査。吉田西太田1934の庁舎住所は一致するが、案内図から数値は推定しない。1階夜間休日受付と同庁舎を同定したが庁舎の明示数値marker未取得。
- **キターレ**: キターレ公式アクセス・市公式案内を調査。市地図URLのlat/lngは検索モードの表示中心で施設markerではない。公式サイトでも河井町4-66-1の建物地点を明示する座標を確定できず。
- **能登ワイン株式会社**: 能登ワインの県公式観光施設座標を発見したが、同ページ住所は旭ケ丘リ5番1、台帳・町配布案内はり5番6。地番の違いと配布建物の関係が未解消のため施設名だけで採用しない。
- **清津渓谷トンネル エントランスPeriscope**: 清津峡公式案内・県観光を調査。県観光の数値は清津峡渓谷トンネル全体の地点。エントランスPeriscopeはトンネル入口から離れた別施設であり、トンネル点をショップへ流用しない。

- **勝山市長尾山総合公園 管理事務所**: かつやま恐竜の森公式アクセス・園内案内を調査。長尾山総合公園の広域案内と管理事務所建物を分離できない。サイトのGoogleリンクに含まれる別駐車場地点や公園代表点を管理事務所へ流用しない。
