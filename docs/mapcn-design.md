# カード探索UIの判断基準

Vite + React + mapcn / MapLibreで、配布施設を探し、受取後に蓋へ向かう。起動・ビルド・検証は [web/README](../web/README.md)、公開と外部地図の設定は [配信手順](deployment.md) を参照。

## 地図と検索

- 主なピンは配布施設。蓋は別の目的地として詳細から選ぶ。通常ピンと地域の件数はMapLibreのsource/layerで描き、距離によるクラスタは使わない。
- 全国→地方→県→施設へ進む。件数は位置確定済みの施設に載るカードIDの重複を除いて数える。配布状態・在庫の保証ではなく、蓋は数えない。施設の県と一覧のカードの県が異なることがある。
- 地図エンジン（MapLibre と全国のピン `pins.json`）は、取得・初期化・交代の3つの時点に分けて進める（`web/src/pages/map/use-map-engine.ts`、`map-page.tsx`）。
  - 取得：最初の画面（全国・地方は最初から、県は施設が描けた）が描けたら、地図のコード（`card-map` と MapLibre）を読み始める（`readMapEngine`）。回線は使うが、地図はまだ作らない。
  - 初期化：地図を作り、`pins.json` を取る。メインスレッドをしばらく占めるので、取得が済み、画面が待つ通信が終わり、使用中のもの（県図の一覧・押した所の候補・押している指・検索の入力・別の画面の表示）がなく、最後に押す・打つ・回すから2秒たったときに始める。指でずらす・つまむ・ホイール、県図に出ていないカードの選択（検索・URL・蓋・他県の窓口）、県のファイルの取得の失敗（通信の失敗・5xx）では、すぐに始める。県のファイルが消えていたとき（404・410）は始めず、再読み込みで今の世代へ切り替える。
  - 交代：地図の準備ができても、県図・全国図が使用中（一覧・候補を開いている、指が下りている）の間は図を残し、一覧を選ぶか閉じる、指を離して押した結果が出るのを待ってから、同じ位置・同じ縮尺で入れ替える。
  - 地図の初期化に失敗しても、県図・一覧・検索・詳細は残る。失敗の知らせは画面上部のお知らせの列に出し（`map-notices.tsx`）、県図の「施設の一覧」と出典に重ねない。全国図・地方の図と、知らせの後に開いた県図は、その列を避けて描く。
- 地図を渡すまでは、同じ位置に海岸線と件数のバッジを DOM で描き（`level-stage.tsx`）、地方と県の選択を受け付ける。選んだ階層は履歴に入り、地図はその階層で開く。カメラは `stage-camera.ts` が MapLibre の `fitBounds` と同じ式で求める。配置（バッジの位置・大きさ・押せる範囲、行の一覧にするか、海岸線の位置）は `level-placement.ts` が決める。
  - 全国図は地図の HTML がはじめから持ち、ページのスクリプトを待たずに出る。ビルドが検索バーと全国図（海岸線・地方の名前と件数・出典）を HTML に書き、HTML の中の小さな同期スクリプト（`web/src/map-stage-main.ts`、`web/src/pages/map/first-stage.ts`）が、最初の描画の前に、React と同じ `level-placement.ts` で画面に合わせて置く。ページのスクリプトが起動すると、同じ絵の `LevelStage` に置き換わる。`LevelStage` は大きさの測定を測った描画の中で反映するので、置き換えの間に未配置のコマは出ない。
  - HTML の全国図を出すのは、全国の段階を開く URL だけ。カードの詳細（`?card=`）、フレンドの地図（アカウント有効のビルドの `?friend=`）、履歴に地方・県が残る再読み込み、全国で県のバッジを出すほど大きい画面では HTML の図を取り除き、ページのスクリプトに任せる。フレンドの地図では、公開の検索バーも同じスクリプトが最初の描画の前に取り除く。
  - ページの起動前に押した地方は、押した印（`aria-current`）を付けて `#root` に残し（`early-choice.ts`）、ページは起動したときに一度だけ、その地方で開く（`use-map-navigation.ts`）。ページのスクリプトが読み込めない・起動できないときは、押せば一覧 `/cards` へ移る。JavaScript が動かないときは HTML の図を出さず、`noscript` から一覧へ案内する。
  - 全国・地方の件数はビルドが HTML に埋める（`web/src/domain/map-summary.ts`、`vite.config.ts`）。数え方は地図と同じ `countPins`。
  - 地方を選ぶと、その地方の県だけを出し、その県々の施設のファイルを先に取る。バッジと県名が重なる画面（小さいスマホ、横向き）では、バッジの代わりに行の一覧を出す。重なりの判定と、バッジごとの押せる範囲は `stage-layout.ts`。
  - 件数は、数える対象が決まるまで出さない（フレンドの記録や絞り込みに使う記録が届く前は地名だけ）。記録で絞る件数は HTML の件数を使わず、全国のピンと記録から数える。
  - 文字は地図と同じく端末の sans-serif で書く。同じ位置で地図に入れ替わるので、字の形をそろえる。ページも Web フォントを配らず、端末のフォントで書く（`web/scripts/perf/size-budgets.mjs` が検査する）。
- 県を選ぶと、その県の施設所在地のファイル（`places-NN.json`、施設の id・扱うカード・座標・状態・名前と、隣県との境界線）を取り、県図を描く（`pref-stage.tsx`）。地図と同じ状態色の四角いピンを実際の座標に置き、押せばその施設の詳細を開く。ファイルが届くまでは地方の画面に県を選択中として示す。
  - 指の下（指なら22px、マウスなら12px）に施設が複数あれば、押した点を動かさずに4倍へ拡大する（`stage-press.ts`）。ズーム15（中部で指の幅が約40m）でも分けられない施設、同じ座標の窓口は、名前を罫線の台帳に並べて選ばせる。ピンの位置は寄せない。拡大した県図は、道しるべの県名から県全体へ戻せる。
  - 本土の範囲に入らない施設（小笠原など）も座標を寄せない。県図の「施設の一覧」から、図の外の施設を含めて選べる。キーボード・読み上げも同じ一覧で選ぶ。
  - 県図はドラッグ・ピンチ・ホイールで動く（`stage-gestures.ts`）。指の間は描いた図をそのまま動かし、指を離したら、指の下にあった地点をそのままにした view で描き直す。縮尺の上限・下限を超える分は、動かさなかった点を中心に上限・下限で止める（`stage-camera.ts` の `boundedMove`）。
  - 地図への交代は、県図の中心・ズーム（`StageView`）をそのまま `jumpTo` に渡す。準備ができた後に県図が動けば、裏の地図も同じ view へ移る。県図で選んだ施設は、交代で地図を動かさない。投影の式は `stage-camera.ts` を共有する。
  - 交代した地図でピンを選ぶと、選択の印はすぐに描き、カメラの移動は詳細を描いた次の描画の後に始める（`map-runtime.ts`）。
  - 出典は右下に小さく常に出す（県図・全国図の間は国土数値情報、地図に交代したら地図の出典）。
- アプリのレイヤー（ピン・件数）は背景スタイルが入った時点で載せ、背景タイルの完了を待たない。地図を渡す時点は階層で分ける（`map-runtime.ts`）。全国・地方は最初の表示が出そろったとき（`idle`）。県を選んだとき・カードを選んだときは、ピンが描かれて押せるようになったときで、背景タイルは後から埋まる。表示するピンがないときは、背景の表示がそろった時点（`idle`）で地図に切り替える。渡した後のタイルの失敗は警告として扱う。
- カメラの固定範囲は本土側を対象とし、離島のピンは消さない。[生成方法](../tools/map/README.md)を参照。
- 地図の初期化・背景取得に失敗しても検索・一覧・詳細を使えるようにする。位置未確定の施設を確定座標として経路案内へ渡さない。
- 地図検索は全国を対象とし、地図のピンを絞らない。位置のないカードも探せる。独立した一覧 `/cards` は地図コードなしで起動できる。

階層・件数・カメラの範囲は `web/src/features/map/map-levels.ts`、パネルを避ける余白は `map-layout.ts`（パネルの位置はページの `web/src/pages/map/map-surround.ts` が測って数値で渡す）、全国の表示配置は `area-layout.ts`、地図と選択の接続は `web/src/pages/map/` を参照。閾値・寸法・色はコードを正本とする。

## 詳細の道順と窓口

- 「① 受け取る」「② 蓋を訪ねる」を分け、選択した窓口・段と地図の強調・Google Mapsの行き先を一致させる。複数窓口と位置未確定の窓口も残す。
- スマホの要約では今の行き先ともう一方への操作を届く位置に残す。終了・一時中止の注意を縮約で消さない。全体表示と一覧では窓口の情報をすべて確認できるようにする。
- 住所は位置未確定・取り下げ済み施設の検索先を確認するために表示する。電話番号は詳細・カードページへ表示しない。
- 許諾画像はクレジットと一緒に出し、切り抜き・角丸・重ね表示・加工をしない。読込失敗時は画像と枠を消す。許諾・追加は [データ保守](data-maintenance.md#カード画像の追加) に従う。

窓口の整理と初期選択は `web/src/domain/card-counters.ts`、地図上の詳細の描画は `web/src/features/card-detail/`、カードページの描画は `web/src/pages/card/static-pages.tsx`、段・窓口の選択は `web/src/pages/map/use-detail-selection.ts`、シートは同ディレクトリの `use-detail-sheet.ts`・`use-explorer-layout.ts`・`detail-sheet.css` を参照。

## 描画と寿命

地図は文書に最大1個とし、画面を隠している間はカメラとデータ反映を止める。私的データと遅延応答の扱いは [ハーネス](harness.md#同じ文書で切り替える画面) に従う。

配色はOS設定へ追従し、文字・操作・ピンのコントラストと常時見える出典を保つ。CSSは `web/src/shared/ui/tokens.css`、地図描画は `web/src/features/map/map-theme.ts` と `basemap-style.ts`、検査は `tools/design/theme-contrast.mjs` を参照。

背景はCARTOのスタイルを使い、`VITE_MAP_STYLE_URL` で交換する。APIキー不要という説明だけで公開用途の許諾を判断しない。MapLibre Workerは導入版と同じものを自前配信する。mapcn由来の変更範囲・ライセンスは [MAPCN_PROVENANCE](../web/MAPCN_PROVENANCE.md)、地図出典は [THIRD_PARTY_DATA](../web/THIRD_PARTY_DATA.md) に残す。
