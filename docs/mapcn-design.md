# mapcn によるカード探索 UI

## 決定と対象

Vite + React + mapcn / MapLibre を標準画面にする。目的は、地図を動かしてカードを探し、詳細から Google マップへ渡すまでの操作を滑らかにすること。自前のカードデータ生成は維持し、背景地図の自作を必須条件から外す。認証・バックエンドは将来の別依頼で扱う。静的配信は [デプロイ手順](deployment.md) を参照する。

全画面の地図サイズを保つ。地図上のバーから全画面の検索を開き、検索結果と詳細は同時に表示しない。

## 採用理由

- **MapLibre** はベクトル地図とカードのレイヤー描画を担当する。表示する範囲に応じて背景タイルを取得し、各ピンに HTML 要素を作らない。移動中の座標を毎フレーム React state に流さず、カメラ操作は MapLibre に任せる。
- **mapcn** は React の地図コンポーネントと操作 UI を提供する。公式 CLI が生成したソースをリポジトリに保存し、必要なら MapLibre の API を直接使える。単独で通信量や FPS を改善する技術とは扱わない。
- **React** は検索、選択、カード詳細の状態を管理する。mapcn を使うため採用する。Next.js のサーバー機能は不要なので Vite を継続する。
- **Tailwind / shadcn 設定** は mapcn の前提として導入する。完成済みページのブロックを丸ごと入れず、地図コンポーネントと必要な UI だけを使う。
- **APM** は公式スキルの版と内容をそろえる開発用の依存管理。Bun の実行時依存とは別で、ブラウザーには配信しない。[導入・更新方法](development-agents.md)を参照。

Effect、認証、バックエンドの候補は引き続き保留する。Bun / mise / Vitest / Oxlint / Oxfmt / lefthook と Go のデータ処理は継続する。

## データと操作

既存の `Data` / `Pin` / カード・施設の関連を使い、座標は GeoJSON の `[経度, 緯度]` に変換する。蓋と配布場所、配布状態、参考位置の区別を保持する。カード数とピン数は同じではなく、地図の数字はピン数を示す。

カードの通常ピン・地域の数字・選択状態は MapLibre の source/layer で描く。距離ベースのクラスタは使わない。

### 全国→地方→都道府県の表示

スマホで全国を収めるとズーム約4で、都道府県の数字47個は押し分けられない。そのため全画面幅で次の階層にする。

| 階層 | 出すもの | 押したとき |
| --- | --- | --- |
| 全国 | 9区分の数字（北海道、東北、関東、中部、近畿、中国、四国、九州、沖縄） | 区分の範囲へ移動。北海道と沖縄は1県なので直接県を開く |
| 地方 | その区分の都道府県の数字。開いた区分以外の数字は隠す | 県の範囲へ移動して県を開く |
| 都道府県 | その県の全ピン。ズーム7以上では隣県のピンも薄く出す | 近くのピンをまとめて詳細一覧へ。多すぎるときは拡大 |

- 表示はズームと選択中の区分・県で決める。ズーム5.6未満は区分の数字、5.6以上7未満は都道府県の数字、7以上は全ピン。開いた区分の都道府県の数字はズーム7未満で出す。開いた県のピンは、アプリのカメラ移動ではズームによらず出すが、利用者が縮小してズーム7を下回ると県を閉じて数字に戻す。同様にズーム5.6を下回ると区分を閉じる。開いた時点で境界より低い北海道などは、開いたズームより0.5以上縮小したときに閉じる。この判定は `web/src/features/map/map-levels.ts` の純粋関数に置く。範囲と数字の配置は `tools/map/generate.py` が生成する `web/src/prefectures.ts` を使う。
- 既定のCARTO背景では、県境をズーム5.6で薄い線から濃い線へ切り替え、7以上も濃いままにする。5.6未満でも区分を開いている間は全国の県境を濃くするが、低ズームのタイルに県境データがない範囲では表示できず、交換用スタイルには適用しない。
- 数字は位置確定済みの配布施設ピン数で、配布終了・一時中止・要確認も含む。蓋は数えない。詳細の「蓋の位置へ」で選択した蓋を表示しても数字は変えない。
- 開いた県があるときは、ズーム7以上で他県のピンを薄くする。隠さない。開いた県がなければ全ピンを通常の濃さで出す。
- 区分の移動先は固定範囲とする。県の移動先は、固定範囲の内側にあるピンの外接範囲とし、県内のピンのない山間部などで縮小しない。範囲外の離島のピンは表示するが、カメラの計算には含めない（小笠原の1件で東京が縮小されるため）。範囲内にピンがない県は固定範囲を使う。
- 地図ヘッダーの「一覧」は、開いた県を `/cards.html?pref=…` に渡す。一覧にカード数と配布施設ピンの有無の件数を出す。地図には全国と地方へ戻るパンくずを置き、ブラウザーの戻る操作でも階層を戻す。
- 都道府県一覧は独立した `/cards.html` に置く。地図コードを取得せず、県の選択・検索・詳細を使える。
- 地図上の検索ボタンはネイティブ dialog の全画面検索を開く。空欄では案内を表示し、全国の検索結果を既存順序で50件ずつ「さらに50件表示」で追加する。ピンのないカードも検索でき、結果選択で詳細を開く。検索は地図のピンを絞らない。地図コードやWebGLが失敗しても検索と詳細を使える。
- 県はピンの生成時に `Pin.pref` として持たせる。配布施設は住所の都道府県を優先し、住所にないときはカードの都道府県を使う。どちらからも決まらない配布施設ピンは生成を失敗させる。

同一座標や近接するピンは、タップ位置の周囲を問い合わせてカード ID を重複排除し、全件の一覧を開く。施設・蓋をまたぐ同一カードの重複は一覧に出さない。

検索・一覧は地図の初期化より先に使える。地図モジュール・背景・WebGL が失敗してもカードの詳細とリンクは使用できる。地図準備前の選択は地図が使える時点で反映する。位置未確定の施設を確定座標として経路案内に渡さず、名称・住所の検索を使う。裸の `/` は全国を表示し、前回の範囲は復元しない。`/?card=…` は詳細を復元し、配布施設ピンがあるときだけ全対象へ移動する。URL選択と地図の階層は戻る・進むで復元し、履歴の `mapFocus` を保持する。動きを減らす設定ではカメラアニメーションを省く。

### 県境と区分境界

CARTO のズーム5タイルには県境が欠けており、ズーム5.6で色やフィルターを変えるだけでは全県を表示できない。N03-20260101 の県間共有セグメントを抽出・結合し、一度だけ簡略化した `web/src/pref-borders.json` を使用する。海岸線は含めない。区分境界は既存の `prefectures.ts` の `area` が異なる県の組から決める。

全国・ズーム5.6未満は区分の数字と区分境界、5.6以上7未満は県の数字と全県の県境を表示する。区分を開いている間は7未満でも県境を表示し、他の区分の数字は隠す。選択した県自身の数字を省略する仕様は維持する（北海道・沖縄を開いた場合は県の数字なしでピンになる）。7以上は自前の線を消し、背景の詳細な `boundary_state` を濃くする。背景の元レイヤーを7未満用に複製して原色・フィルターを保持し、自前の県境と重なる5.6以上7未満だけ隠す。背景に該当レイヤーがなければ操作を省略する。

JSON は `?url` によるハッシュ付きアセットとし、地図の ready 通知後に取得する。取得失敗は線を省略するだけで、地図・ピン・ready の待ち時間に伝播させない。ズーム条件はレイヤーの範囲と式で評価し、境界の描画設定は focus のモードが変わったときだけ更新する。

## 配信と外部依存

通常画面は mapcn の明るい CARTO 背景を利用し、`VITE_MAP_STYLE_URL` で互換スタイルへ交換できる。出典は MapLibre の attribution を表示する。mapcn の「API キー不要」という説明は、すべての公開用途が無条件に利用可能という意味ではない。CARTO の現行案内にはキー・用途別上限があるため、公開前に利用条件と配信先を確定する。配信の有効化は [デプロイ手順](deployment.md) に従う。

公式コンポーネント既定の unpkg Worker URL は、公式ドキュメントに従って自前配信へ変更する。インストールした MapLibre と同じ版の Worker / shared モジュールを build と dev の両方で配信する。mapcn ソースの変更はこの設定と整形に限定する。公式由来の冗長なオブジェクト展開に対する Oxlint の一規則だけ、生成ファイルに限定して無効化する。他のコードには適用しない。

## UIの責務分離

地図失敗を一覧の取得・表示へ伝播させず、詳細の描画検査をブラウザーのグローバル状態から独立させるために分割する。ページは `web/src/pages/`、詳細と取得と地図は `web/src/features/`、カードの純粋関数は `web/src/domain/`、共通補助は `web/src/shared/` を参照。深いpropの受け渡しはないためProviderは追加しない。

### 地図ページ

`pages/map/map-page.tsx` が取得・地図・検索・詳細を組み立てる。`use-map-navigation.ts` は mapFocus と popstate、`use-detail-selection.ts` は選択・URL 同期・施設と蓋の切り替えを持つ。`use-detail-sheet.ts` は閉じる・たたむ・フォーカス復帰とドラッグを接続し、`map-detail-sheet.tsx` は既存の section と子要素・ARIA・Escape の伝播停止を維持して詳細を描く。通知は `map-notices.tsx`、ResizeObserver と CSS 変数は `use-explorer-layout.ts`、選択時のフォーカスと描画時間は `use-selection-metrics.ts` に置く。

検索中の選択ピンは定数の空配列を渡す。検索索引は純粋な `domain/card-selection.ts` 内で data 単位に保持する。シートの高さ・safe-area は読み取りをまとめてから CSS 変数へ書き込む。`features/map` の MapStage・Adapter・selectionPadding の呼び方は維持する。

検索セッション（語・表示数・スクロール・選択行）は `useMapUrlState` と `history.state.mapSearch` で管理する。検索を開くと履歴を追加し、カード選択で詳細のURLを追加する。バーとブラウザー戻るで結果へ戻り、行にフォーカスする。検索由来の詳細を閉じると、cardをreplaceで除き、語をバーに残す。

詳細は1000px以下（600px以上かつ高さ540px以下の横画面を除く）で画面下端のシートに表示する。高さは内容に応じ、上限50dvhで本文のみスクロールする。地図のタップやズーム、またはハンドル・見出しから下へ80px、0.5px/ms以上のスワイプで見出しだけにたたむ。ドラッグや回転ではたたまない。本文が先頭までスクロールされているときは本文からも下へスワイプできる。たたむ操作は履歴を変えない。シートの移動は `transform` だけで行い、高さは変えない。たたんだシートは、タップか上スワイプで開き、×か下へ40px、0.5px/ms以上のスワイプで閉じる。PCの右パネルと短い横画面の左パネルは維持する。シート高をレイアウト値で測り現在地と出典表示を上へ動かす。単一ピンはバーとシートの間で高さ25%に寄せ、複数ピンは見える範囲に収める。
