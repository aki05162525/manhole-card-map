# mapcn によるカード探索 UI

## 決定と対象

Vite + React + mapcn / MapLibre を標準画面にする。目的は、地図を動かしてカードを探し、詳細から Google マップへ渡すまでの操作を滑らかにすること。自前のカードデータ生成は維持し、背景地図の自作を必須条件から外す。アカウント・記録・フレンドの API と画面は [アカウント設計](account-design.md) に従って実装済みで、地図からは記録の絞り込みと回収済みの印だけを扱う。静的配信は [デプロイ手順](deployment.md) を参照する。

全画面の地図サイズを保つ。地図上のバーから検索を開き（幅1001px以上では左上の420pxパネル、それ以外は全画面）、検索結果と詳細は同時に表示しない。

## 採用理由

- **MapLibre** はベクトル地図とカードのレイヤー描画を担当する。表示する範囲に応じて背景タイルを取得し、各ピンに HTML 要素を作らない。移動中の座標を毎フレーム React state に流さず、カメラ操作は MapLibre に任せる。
- **mapcn** は React の地図コンポーネントと操作 UI を提供する。公式 CLI が生成したソースをリポジトリに保存し、必要なら MapLibre の API を直接使える。単独で通信量や FPS を改善する技術とは扱わない。
- **React** は検索、選択、カード詳細の状態を管理する。mapcn を使うため採用する。Next.js のサーバー機能は不要なので Vite を継続する。
- **Tailwind / shadcn 設定** は mapcn の前提として導入する。完成済みページのブロックを丸ごと入れず、地図コンポーネントと必要な UI だけを使う。
- **APM** は公式スキルの版と内容をそろえる開発用の依存管理。Bun の実行時依存とは別で、ブラウザーには配信しない。[導入・更新方法](development-agents.md)を参照。

Effect は引き続き保留する。Bun / mise / Vitest / Oxlint / Oxfmt / lefthook と Go のデータ処理は継続する。

## データと操作

既存の `Data` / `Pin` / カード・施設の関連を使い、座標は GeoJSON の `[経度, 緯度]` に変換する。蓋と配布場所、配布状態、参考位置の区別を保持する。カード数とピン数は同じではなく、地図の数字はピン数を示す。

カードの通常ピン・地域の数字・選択状態は MapLibre の source/layer で描く。距離ベースのクラスタは使わない。

### 全国→地方→都道府県の表示

スマホで全国を収めるとズーム約4で、都道府県の数字47個は押し分けられない。そのため全画面幅で次の階層にする。

| 階層 | 出すもの | 押したとき |
| --- | --- | --- |
| 全国 | 9区分の数字（北海道、東北、関東、中部、近畿、中国、四国、九州、沖縄） | 区分の範囲へ移動。北海道と沖縄は1県なので直接県を開く |
| 地方 | その区分の都道府県の数字。開いた区分以外の数字は隠す | 県の範囲へ移動して県を開く |
| 都道府県 | その県の全ピン。ズーム7以上では隣県のピンも薄く出す | タップに最も近いピン1つの詳細またはカード一覧へ |

- 表示はズームと選択中の区分・県で決める。ズーム5.6未満は区分の数字、5.6以上7未満は都道府県の数字、7以上は全ピン。開いた区分の都道府県の数字はズーム7未満で出す。開いた県のピンは、アプリのカメラ移動ではズームによらず出すが、利用者が縮小してズーム7を下回ると県を閉じて数字に戻す。同様にズーム5.6を下回ると区分を閉じる。開いた時点で境界より低い北海道などは、開いたズームより0.5以上縮小したときに閉じる。この判定は `web/src/features/map/map-levels.ts` の純粋関数に置く。地方の移動先・県の範囲と県の数字の配置は `tools/map/generate.py` が生成する `web/src/prefectures.ts` を使う。全国の9地方の表示用配置は `web/src/features/map/area-layout.ts` で管理する。
- 県境はズーム5.6または区分を開いたときに自前の線を強調し、7以上は背景の詳細線に切り替える（後述）。色は `--boundary #7b756a`、幅1.25px、破線はz9未満で `[2,2]`、z9以上で `[3,2]`。
- 数字は位置確定済みの配布施設ピン数で、配布終了・一時中止・要確認も含む。蓋は数えない。詳細の「蓋の位置へ」で選択した蓋を表示しても数字は変えない。
- 開いた県があるときは、ズーム7以上で他県のピンを薄くする。隠さない。開いた県がなければ全ピンを通常の濃さで出す。
- 区分の移動先は固定範囲とする。県の移動先は、固定範囲の内側にあるピンの外接範囲とし、県内のピンのない山間部などで縮小しない。範囲外の離島のピンは表示するが、カメラの計算には含めない（小笠原の1件で東京が縮小されるため）。範囲内にピンがない県は固定範囲を使う。
- 地図ヘッダーの「一覧」は、開いた県を `/cards.html?pref=…` に渡す。一覧にカード数と配布施設ピンの有無の件数を出す。地図には全国と地方へ戻るパンくずを置き、ブラウザーの戻る操作でも階層を戻す。
- 都道府県一覧は独立した `/cards.html` に置く。地図コードを取得せず、県の選択・検索・詳細を使える。
- 地図上の検索ボタンはネイティブ modal dialog の検索を開く（幅1001px以上は420pxパネル、スマホは全画面）。空欄では案内を表示し、全国の検索結果を自治体名の完全一致・前方一致・部分一致・その他の順で、同じ段では県コード・カード番号順に50件ずつ「さらに50件表示」で追加する。ピンのないカードも検索でき、結果選択で詳細を開く。検索は地図のピンを絞らない。地図コードやWebGLが失敗しても検索と詳細を使える。
- 県はピンの生成時に `Pin.pref` として持たせる。配布施設は住所の都道府県を優先し、住所にないときはカードの都道府県を使う。どちらからも決まらない配布施設ピンは生成を失敗させる。

タップ位置の周囲±12pxを問い合わせ、画面上の距離が最も近いピン1つを選ぶ。同距離なら描画順で上にあるピンを優先し、件数による拡大はしない。選んだピンのカードが1枚なら詳細、複数なら「この場所のカード」一覧を開く。強調とカメラ移動はそのピン1つに限定し、一覧から詳細を開いた後や一覧へ戻った後も維持する。「蓋の位置へ」で表示した蓋ピンも同じ扱いとする。検索・独立した一覧・共有URLからのカード選択は、従来どおりそのカードの全配布施設ピンを対象にする。`onSelect(cardIds, pinId)` で地図からページへ選んだ場所を渡し、URLは `?card=…` のままとする。

検索・一覧は地図の初期化より先に使える。地図モジュール・背景・WebGL が失敗してもカードの詳細とリンクは使用できる。地図準備前の選択は地図が使える時点で反映する。位置未確定の施設を確定座標として経路案内に渡さず、名称・住所の検索を使う。裸の `/` は全国を表示し、前回の範囲は復元しない。`/?card=…` は詳細を復元し、配布施設ピンがあるときだけ全対象へ移動する。URL選択と地図の階層は戻る・進むで復元し、履歴の `mapFocus` を保持する。動きを減らす設定ではカメラアニメーションを省く。

### 背景と状態表示

背景は既定の CARTO Positron、交換用は `VITE_MAP_STYLE_URL`、fixture は無地の `/map-style.json` を使う。`basemap-style.ts` の純粋関数を `setStyle` の `transformStyle` に渡し、type と source-layer で配色する。OpenMapTiles と CARTO の roads / places / buildings に対応し、不明な層は保持する。ライトの水は `#cdd6d5`、建物は `#e0dcd2`、道路は白に0.75pxの縁を重ねる。place / places は日本語名（name:ja、なければname）を使い、ピン段階のz7まで隠す。地名は `#595c58` とし、水上の文字4.5:1・境界3:1を満たす濃さにする。低ズームの地名はアプリの件数ラベルで示す。変換が例外になった場合は元のstyleを返す。

件数は鉄色の丸に紙色の2pxの縁と内輪を重ねる。全国の9地方は `features/map/area-layout.ts` に表示用座標とラベルの左右を明示し、既存の代表点から1.5度以内で、短い地名に合わせて地方の陸側へ配置する。複数県の地方は県代表点の外接範囲、北海道・沖縄は生成済みの本土側範囲内に置く。この範囲検査は海岸線との厳密な包含判定ではないため、実背景の画像でも確認する。実際の地方の範囲と施設座標は変えない。全国の半径はズームで縮めず、地図幅600px以上では件数に応じた16〜26pxを保つ。600px未満では全国の地方だけを1桁13px・2桁14px・3桁以上16px、数字11pxにする。県の段階からは既存の規則に戻す。地方・県とも横のラベルは地名だけとし、件数は丸の中だけに表示する。出典表示には件数の説明を追加しない。地方の地名は13pxの1行で、丸の半径＋4pxの位置に固定し、数字・地名とも重なりを許可して省略を防ぐ。表示の重なりは9地方の表を使った投影テストで検査する。全国の数字はCARTOが配信するMontserrat SemiBoldを使う（Open Sans Semiboldは404になるため使わない）。県の段階のサイズ・衝突回避・フォントは既存のままとする。

全国カメラは `[[127.5,26],[146,45.6]]` を、検索バー下端＋8px・他辺16pxの余白で収める。地図幅600px未満の左右だけ8pxにする。全国の地方のタップは中心から22px以内の最近傍を選び、ラベルも同じ地方へ移動する。412×915と1440×900で9個の丸、ラベル、数字、沖縄の見切れを検査する。ラベルの概算は文字数×13pxとし、ハローと丸の縁も考慮する。表示用座標を変更した場合は実データの背景でも両サイズの画像を確認する。

地図の準備が300msを超えたら刻みの輪を1.2秒・12段で回し、reduced-motionでは停止する。準備完了時はロゴが180msで拡大して消え、reduced-motionでは即時に消す。検索は先に使用でき、地図初期化失敗時は検索・一覧が使える案内と再試行を地図面に出す。データ取得失敗とオフラインは上部の帯に表示し、オフラインの基準日はデータの evaluatedAt（なければupdated）から取得する。空の通知面は描画しない。現在地ボタンは48pxの丸で、取得中は外輪を回す。出典は11pxのcompact表示で、PCの詳細パネルは下端に出典の空間を残し、スマホはシートに合わせた持ち上げを保つ。現在地点は鉄色の点・白3px縁・半径16の鉄色15%の輪で示す。

### 県境と区分境界

CARTO のズーム5タイルには県境が欠けており、ズーム5.6で色やフィルターを変えるだけでは全県を表示できない。N03-20260101 の県間共有セグメントを抽出・結合し、一度だけ簡略化した `web/src/pref-borders.json` を使用する。海岸線は含めない。区分境界は既存の `prefectures.ts` の `area` が異なる県の組から決める。

全国・ズーム5.6未満は区分の数字と区分境界、5.6以上7未満は県の数字と全県の県境を表示する。区分を開いている間は7未満でも県境を表示し、他の区分の数字は隠す。選択した県自身の数字を省略する仕様は維持する（北海道・沖縄を開いた場合は県の数字なしでピンになる）。7以上は自前の線を消し、背景の詳細な `boundary_state` を濃くする。背景の元レイヤーを7未満用に複製して原色・フィルターを保持し、自前の県境と重なる5.6以上7未満だけ隠す。背景に該当レイヤーがなければ操作を省略する。

JSON は `?url` によるハッシュ付きアセットとし、地図の ready 通知後に取得する。取得失敗は線を省略するだけで、地図・ピン・ready の待ち時間に伝播させない。ズーム条件はレイヤーの範囲と式で評価し、境界の描画設定は focus のモードが変わったときだけ更新する。

## 配信と外部依存

通常画面は mapcn の明るい CARTO 背景を利用し、`VITE_MAP_STYLE_URL` で互換スタイルへ交換できる。出典は MapLibre の attribution を compact: false で常時表示し、OpenStreetMap contributors と CARTO へリンクする。配布場所の■は状態の色で描き、地図上の凡例パネルは置かない。出典は右下に枠なしの小さな1行で出す。mapcn の「API キー不要」という説明は、すべての公開用途が無条件に利用可能という意味ではない。CARTO の現行案内にはキー・用途別上限があるため、公開前に利用条件と配信先を確定する。配信の有効化は [デプロイ手順](deployment.md) に従う。

公式コンポーネント既定の unpkg Worker URL は、公式ドキュメントに従って自前配信へ変更する。インストールした MapLibre と同じ版の Worker / shared モジュールを build と dev の両方で配信する。mapcn ソースの変更はこのWorker設定と整形、およびアプリ側の配色変換・遅延ローダー・初期エラー受信を渡す最小の拡張に限定する。詳細は `web/MAPCN_PROVENANCE.md` を参照する。公式由来の冗長なオブジェクト展開に対する Oxlint の一規則だけ、生成ファイルに限定して無効化する。他のコードには適用しない。

## UIの責務分離

地図失敗を一覧の取得・表示へ伝播させず、詳細の描画検査をブラウザーのグローバル状態から独立させるために分割する。ページは `web/src/pages/`、詳細と取得と地図は `web/src/features/`、カードの純粋関数は `web/src/domain/`、共通補助は `web/src/shared/` を参照。回収の記録の状態は地図・検索・詳細で共通のProviderに保持する。記録機能は `VITE_ACCOUNTS_ENABLED=true` のビルドでだけ読み込み、フラグが無効ならProviderも読み込まない。カードごとの保存中状態・操作の世代番号・確定と巻き戻しはProviderが管理し、詳細を閉じても保存処理と失敗通知を続ける。

地図の描画は次の責務に分ける。`MapStage` の遅延 import、`Adapter`、`card-map.tsx` からの `selectionPadding` の呼び出し方は維持する。

| ファイル（`web/src/features/map/`） | 責務 |
| --- | --- |
| `card-map.tsx` | 地図・境界・レイヤー・操作 UI の組み立て |
| `map-boundary.tsx` | React のエラー境界、初期化失敗と準備後の警告の区別、20秒のタイムアウト |
| `map-resources.ts` | ピン画像、source と layer の ID・設定・追加順序 |
| `map-layout.ts` | 選択時の DOM 計測。余白の計算は `paddingForSelection` に渡す |
| `map-layers.tsx` | mapcn の準備状態と props を runtime へ同期 |
| `map-runtime.ts` | `createMapRuntime` による登録・イベント・Adapter・ready・破棄の管理 |

runtime はスタイルの準備前からエラーを購読し、準備後の登録は一度だけ行う。リスナーの解除と source・layer・画像の破棄も同じ runtime が持つ。破棄後の選択・focus・現在地の更新と県境取得の完了は地図を更新しない。親が先に地図を破棄している場合は残存リソースだけを確認する。

各 runtime の初回集計後は `countPinsSource` の参照が変わったときだけ再計算し、ズームの表示階層・focus・集計元が変わったときに COUNTS を同期する。初回の source 登録直後や、focus と集計元を同時に変更したときの二重更新を避ける。選択から focus の順にカメラ操作を適用し、ready 時の初期カメラは準備前の選択を上書きしない。県境は ready 通知後に取得し、完了時点の focus を適用する。

### 地図ページ

`pages/map/map-page.tsx` が取得・地図・検索・詳細を組み立てる。`use-map-navigation.ts` は mapFocus と popstate、`use-detail-selection.ts` は選択・URL 同期・施設と蓋の切り替えを持つ。`use-detail-sheet.ts` は閉じる・たたむ・フォーカス復帰とドラッグを接続し、`map-detail-sheet.tsx` は既存の section と子要素・ARIA・Escape の伝播停止を維持して詳細を描く。通知は `map-notices.tsx`、ResizeObserver と CSS 変数は `use-explorer-layout.ts`、選択時のフォーカスと描画時間は `use-selection-metrics.ts` に置く。

検索中の選択ピンは定数の空配列を渡す。検索索引は純粋な `domain/card-selection.ts` 内で data 単位に保持する。シートの高さ・safe-area は読み取りをまとめてから CSS 変数へ書き込む。`features/map` の MapStage・Adapter・selectionPadding の呼び方は維持する。

検索セッション（語・表示数・スクロール・選択行）は `useMapUrlState` と `history.state.mapSearch` で管理する。検索を開くと履歴を追加し、カード選択で詳細のURLを追加する。バーとブラウザー戻るで結果へ戻り、行にフォーカスする。検索由来の詳細を閉じると、cardをreplaceで除き、語をバーに残す。

詳細は1000px以下（600px以上かつ高さ540px以下の横画面を除く）で、要約・全画面・たたむの3状態を持つ。高さ100dvhのシート1つをtransformで動かし、要約の高さは実測して `min(56dvh, 440px)` 以下に収める。ピン・検索からは要約を開く。上スワイプはたたむ→要約→全画面、下スワイプは全画面→要約→たたむ→閉じると1段ずつ進む。全画面の本文からの下スワイプはスクロール先頭だけで受け付ける。要約からは「詳しく」・つまみ・本文のタップでも全画面へ進む。地図の空白タップとズームでたたむのは要約だけで、横移動・回転ではたたまない。全画面だけ同じURLで `sheet: "full"` の履歴を追加し、UIから要約へ戻る操作は `history.back()` を使う。背景をinertにし、dialog・aria-modalを付け、見出しへフォーカスする。要約に戻ると「詳しく」へ返す。PCと短い横画面のパネルを維持し、配布状態は施設名の直下にそろえる。選択の余白と現在地・出典表示の持ち上げにはシート全体の高さではなく要約の実測値を使う。スマホの単一ピンは画面上端から高さ25%の位置へ寄せ（バーやシートに隠れる場合は見える範囲に調整）、最大ズーム15で移動する。複数ピンは見える範囲に収める。

## OS に合わせた配色

色は `shared/ui/tokens.css` のライト値と `prefers-color-scheme: dark` の上書きで管理する。操作の境界は `--control-border`、装飾の罫線は `--rule` と区別する。反転した鉄の面には `--on-iron` を使う。入力ヒントはブラウザー既定の半透明色に依存せず `--ink-muted` で描く。

MapLibre は CSS 変数を解決しないため、`features/map/map-theme.ts` に描画用の値を持つ。mapcn の `theme="light"` はソーススタイルを固定するための指定で、画面の配色を固定する指定ではない。初回のスタイル変換と runtime の OS 設定の購読で、背景・文字・境界・件数・現在地・ピン画像を再配色する。ライトへ戻す際は配信元の元の paint を復元する。購読は runtime の破棄時に解除する。配布施設の四角いピンの2pxの縁と白抜き部分は、ライトでは白、ダークでは紙色 `#141816` で描く。選択の照準の外輪は白を保つ。非選択県の不透明度はライト0.35・ダーク0.9とし、暗い縁でも記号の地図上のコントラストを保つ。ダークの水は `#08151b` とし、陸との識別の目安を1.2:1以上にする。

`mise exec -- node tools/design/theme-contrast.mjs` は両テーマの文字（4.5:1）・操作の非文字（3:1）・装飾（WCAG 1.4.11 の対象外、視認性の目安1.5:1）を分類して計算する。地図のパレットもこのコマンドでソースから読み取り、ピンと縁・地図、暗い非選択ピン、水上の地名、陸と水（識別の目安1.2:1）を表にして検査する。`map-theme.test.ts` でも描画用パレットとの対応を確かめる。実データの障害表示は、稼働中の専用サーバー（4187）に対して `node tools/design/theme-fault-server.mjs` で手動検査できる。4188 の `/__theme-test/{data-loading,data-failure,map-failure}/{map,cards}` で通信の停止・失敗を模擬し、実データのファイルは変更しない。確認後は両方の試験サーバーを終了する。

幅1001px以上の詳細は角丸の外枠をクリップと影の面にし、本文の `.detail-body` をスクロール領域にする。見出しと閉じるボタンは外枠に残す。外枠自体をスクロールさせると、地図上へ四角い帯が描かれる場合がある。通常の高さの上限は既存の `calc(100dvh - 72px)` を保ち、高さ540px以下の横画面では既存の48%を保つ。

地図と一覧の検索は `search-controls` の幅を基準にする。`@container` の23em未満では入力を独立した行に置き、一覧の検索ボタンはその下、地図の閉じる・消去操作はその上に置く。ヒントは「自治体・施設・番号」を共有し、カード番号を含む完全な説明はラベルに残す。emのしきい値で文字の拡大にも追従する。
