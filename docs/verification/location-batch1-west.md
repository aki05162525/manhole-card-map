Issue #30。2026-11-05 UTC に、現行の未位置612施設から10施設を調べた。結果は**座標提案2施設、保留8施設、担当者による採用0施設**。中国3、九州7を選定し、四国・沖縄は今回選定していない。親の独立レビューと統合判定が必要であり、この調査だけで未位置件数は変わらない。

調査範囲は[選定](../../data/national/location-batch1/west-selection.json)、全10施設の取得日時・URL・hash・原本内位置・停止/再開条件は[成果](../../data/national/location-batch1/west-outcomes.json)に記録した。[取得記録](../../data/evidence/location-batch1/west/retrievals.json)には失敗した取得と探索用資料も残す。原本の再配布条件を確認できない自治体HTML・画像・PDF等は `data/work/location-batch1/west/` に保存し、追跡対象には自作の事実記録を置いた。

計測は選定JSON作成後の10:37:46.840995から成果生成10:51:33.680861まで、壁時計826.84秒。並行取得・画像読解・連絡を含む。選定前の探索、後続レビュー・統合は含まない。共通資料を使ったため施設別の厳密な所要秒は計測していない。

大分は凹形状の重心が建物外に出るため、Shapely **2.2.0** の `representative_point()` を使う。入口・窓口そのものの点ではなく、現配布施設が入る建物の代表点である。探索時の細長い隣接地物は棄却し、最終仕様のBldA feature index 35を採った。館内図の方位は明示されていないため、形状照合に方位の断定を用いていない。

数値原典はGSI試験公開Vectorの最新PMTiles **2026-07-01版**。BldA外形の保存tileから独立計算し、Googleの点・検索結果・地図中心は座標原典にしていない。国内の原典座標系はJGD2011、処理格子はWeb Mercator。WGS84への測地系変換を実施したとは扱わない。小数7桁は保存時の丸めであり、測量精度の保証ではない。丸め後も建物内であることを検査する。

GSIの固定READMEと利用規約で、試験Vectorが基本測量成果以外であり、出典と加工の明示を伴う利用が可能な資料として確認した。基本測量成果の標準ラスターと区別する。ラスター画像は今回の数値原典ではない。必要なVector2tileだけ追跡保存する。PMTiles取得の13 Range応答は206・length・hashを記録し、同じETagであることを確認した。

再現入力は[vector-inputs.json](../../data/evidence/location-batch1/west/vector-inputs.json)、期待点は[derived-points.json](../../data/evidence/location-batch1/west/derived-points.json)。次で保存tileのhash、対象形状、計算値、丸め後の内包を再検証できる。

```sh
uv run --with mapbox-vector-tile==2.2.0 --with shapely==2.2.0 \
  python data/evidence/location-batch1/west/derive.py
```
