# 配布場所中心の試行（2026-11-05）

設計と再生成手順は [配布場所の設計](../distribution-design.md)。外部公開なし。

## 実装

- 標準画面の初期ピンを確認済み配布場所に限定。カード詳細から蓋を個別に表示し、配布場所へ戻れる。全蓋の表示切り替え、施設名・住所の検索を追加。
- 共有施設の全カード選択を維持。施設ごとの時間・状態・出典・確認日を表示。
- Git管理の施設・配布関係台帳、原典指紋、確認期限、通常配布場所ピン、全国品質レポートを追加。
- 座標未確認でも公式の休止・終了情報を採用可能。期限超過・原典変更で再確認待ちへ戻し、古い目的地へのリンクを停止。
- `listdiff` で保存した全国一覧の全フィールドを比較。画像URLでの照合にとどまり、カード番号による同一性判定は別途必要。

## 実データ

30カードの公式情報を調査。19カードについて21件の配布関係を採用し、13窓口の位置を確認。地図には13窓口を表示する。小田原AとCの共有施設ではカードごとの休止状態を保持する。未採用11カード、多摩Aの平日窓口、逗子の休日受付時間などの残件は `data/overrides/distribution-pilot.json` に記録。

位置の確認はAIによる公式施設案内の照合で、現地確認ではない。建物の代表点を使う施設では階・窓口を名前と条件に残す。全件の基礎資料は2026-10-21取得、配布条件の判定日は2026-11-05。新しい公式原典による訂正の確認日は個別に保持する。

同じ台帳と基準日で再生成した `full.json` はSHA256一致：

`6068da023f3bd4cb1e292b3e43877411a1505356e4377bbf02a255a89afb1987`

## 検証

- TDD：台帳適用、原典変更、座標なしの状態訂正、確認期限、未入力座標の誤った0補完、初期ピンと蓋の切り替え、古いリンクの抑止、一覧差分で失敗→成功を確認。
- Go全テスト、Vitest 56件、lint、format、型検査に成功。
- Gitの改行変換で証拠原本のハッシュが変わらないよう `.gitattributes` でHTMLのバイト列を保持。ステージ済みGitオブジェクトから読み直した全40根拠参照もハッシュ一致。
- fixtureビルドと実データビルドに成功。MapLibreの既存500KB超チャンク警告は継続。
- Chromiumの合成データ検査に成功。配布場所→蓋→配布場所、表示切り替え後の操作、共有施設の実際の描画クリック、検索、リンク、キーボード、位置情報、表示範囲復元、オフライン、地図ロード前の選択、WebGL失敗時、旧C/D画面を確認。
- 412×823と1440×900の既存検査を通過。選択ピンがパネルに隠れる不具合を実測したパネル寸法による余白計算で修正。ピン切り替えで地図操作の参照が無効になる問題も修正。

GitHub上のCIはこのブランチで未実行。既存CIに含まれるGoテストが、全件の非追跡素材なしでもチェックインした証拠ファイルを検証する。ブラウザー検査は外部通信を遮断した合成背景であり、実地図の通信速度やスマホ実機性能の合格判定ではない。

## 文書との対応・残件

要件・READMEの初期表示、選択後の蓋表示、検索範囲、施設座標の採用方法を更新した。旧比較検証の測定結果は過去の記録として維持する。

要件の全国配布場所の確定、週次差分確認の運用、代替先の構造化は未達。静的ファイルの状態は時間だけでは変わらず、新しい基準日での再生成が必要。移転先の新設・同じ窓口の複数期間は今後の拡張対象。全国の未確認情報を今回すべて最新化したものではない。
