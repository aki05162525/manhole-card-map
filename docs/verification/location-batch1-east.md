## 2施設の独立した建物代表点候補

- 新居関所史料館：湖西市観光施設CSVに名称・住所・建物名一致の点を発見。現カード案内と公式パンフレットの写真で、歴史的な面番所と史料館を別建物として扱う。GSI Vector BldAの道路沿い細長い建物の重心候補は **34.6948705, 137.5617116**。
- 焼津市観光協会：市の統合公共施設CSVのNO91010008は同住所・同電話の「観光協会1階」。駅南口Wi-Fiは別行・別点。現配布案内と運営者の路面窓口写真を照合し、GSI Vector BldA重心候補 **34.8715085, 138.3188058** を作成した。

CSVは測地系を明記していないため座標の直接採用を避け、施設名付きの位置を建物探索の補助に限定した。数値原典は2026-07-01版の国土地理院最適化ベクトルタイルで、国内タイルの測地系JGD2011と逆Web Mercatorを明示した。CSVと重心は新居5.29m、焼津1.63m離れる。探索補助点から最寄りの別棟までは新居7.46m、焼津4.58mであり、近接一致だけで同棟と承認しない。写真だけでも敷地内の棟を一意確定できない。現施設名付きCSV・住所・写真・原調査を合わせた対応判断を親に委ねる。

全外形、タイルhash、座標、加工方法、再実行スクリプトは[証拠README](../../data/evidence/location-batch1/east/README.md)と[derived-points.json](../../data/evidence/location-batch1/east/derived-points.json)。重心は両外形の内部。小数桁数は測量精度ではない。

## 保留8施設で得たこと

- 掛川城券売所：市トイレデータでは「券売所西側」「二の丸茶室」「公園南東角」に同一座標が反復する。券売所点に置換しない。H25指定管理資料も現棟を確定できない。
- 開国下田みなと：Wi-Fi数値点を発見したが、2階観光協会事務局との棟対応が未完。県道の駅の平面座標もCRS確認なしに変換しない。
- 樹空の森：施設データ2種類の数値を発見したが、一方はGSI建物外。運営者の1階受付案内と2026-11-01年度分配布終了を記録した。親照合で既に`suspended`のため状態変更不要。翌年度発行決定時の案内予定であり、恒久終了・再開日確定とは異なる。
- 潮見坂：観光施設点とAED駅長室点が約77m異なる。駅長室とカード窓口の同棟性は未確認。
- 裾野観光協会：県カタログが2025年更新でも説明の住所は深良451。現ガイド・配布案内は中央公園内千福7-1。更新日の新しさだけで旧住所点を使わない。
- 石廊崎オーシャンパーク：町AED一覧から休憩棟を確認したが座標なし。現在の運営者URLもローカル取得で証明書不一致となり、原本を保存できない。町の年末年始配布関係は維持。
- 南伊豆町観光協会：町観光一覧は住所まで。県道の駅平面数値は測地系・入居棟対応未確定。年末年始の石廊崎とは別施設として保持。
- 沼津観光案内所：テナント情報はアントレ2Fだが、探索したフロアガイドURLはパルシェの構成を返すため棄却。移転広報PDF候補は404で、現駅ビル棟の根拠にはしない。

各施設の次に必要な資料と停止条件は施設別JSONへ記載した。取得できなかったものを調査済み原本としない。

## 検証・限界

地域担当は原本取得hash・保存形式、10施設IDの一意性、候補2点のタイルhashと外形一意性・重心内部性を検査した。再現スクリプト出力が保存結果と一致した。調査経過時間は選定完了から成果作成までの共有壁時計時間としてJSONに記録し、10施設分として足し合わせない。選定前探索・親統合・独立レビューは含まない。

manifest、台帳、配布関係、binding、アプリコードは地域担当では変更していない。現地確認、当日在庫保証、位置採用後の生成・UIテストは担当範囲外で親に引き継ぐ。

古い記述の差分は上記の裾野旧住所、樹空の森の年度状態の解釈、敷地全体点と棟点の区別である。原調査の「HTMLに数値がない」は当時の対象原本についての記録であり、今回の別データ発見によって原文を書き換えない。
