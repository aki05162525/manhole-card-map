# 技術検証 1：GKP 一覧ページの解析

実施日：2026-10-21
対象：GKP「マンホールカード検索」全国一覧（2026-10-21 取得、1,313 行）

## 目的

一覧ページだけから、次の3点をどこまで取り出せるかを確かめる。

1. カード番号（ID）を組み立てられる件数と、画像での補完が必要な件数。
2. 複数の配布場所や曜日などの条件を取り出せるか。
3. 解釈できない行を、黙って捨てずに検出できるか。

## 再現手順

```sh
go run ./cmd/fetchlist                                   # 一覧ページを1回だけ取得し data/raw に保存
go run ./cmd/inspect data/raw/gkp-list-20261021.html     # 集計を表示し、行ごとの結果を data/work/inspect.json に出力
go test ./...                                            # 実際にあった書き方を元にしたテスト
```

解析は保存した HTML に対して行うため、検証のたびに GKP へアクセスしない。

## 結果

### カード番号

どの組み立て方でも、得られるのは候補であり、番号は確定していない。
表の記号を使った候補も、自治体コードは画像名から取っている。

| 候補の組み立て方 | 件数 |
|---|---|
| 表の市町村欄の記号（例：`A001`）と、画像名の自治体コード | 811 |
| 画像名だけ | 499 |
| 組み立てられない（画像名の形が特殊） | 3 |

画像名からの推定は、表の記号と照合できた 789 件のうち 780 件（約99%）で一致し、9 件で食い違った。
食い違いの多くは画像名の末尾が `-02` のもので、画像を差し替えた版と考えられる。
画像名は番号の根拠にならないため、全カードについて番号全体をカード画像の印字と照合して確定する。
組み立てた候補に重複はなかった。

### 配布状態

| 配布状態 | 件数 |
|---|---|
| 配布中 | 1,210 |
| 一時中止 | 96 |
| 配布終了 | 7 |

配布終了のカードは一覧から消えず、配布場所の欄が空になる（6件）。

### 配布場所

| 1枚あたりの配布場所 | 件数 |
|---|---|
| 0 か所（配布終了など） | 6 |
| 1 か所 | 919 |
| 2 か所 | 361 |
| 3 か所以上 | 27 |

- 条件（【平日】【休日】、①②など）つきの場所を持つカードは 391 件。
- 同じ建物の別窓口で住所が一度しか書かれていないとみなし、隣の場所から住所を補ったカードは 128 件。補ったことは結果に記録している。
  補完の規則が正しいとは確かめていない。公開前に 128 件を人が確認し、同じ建物だという根拠が取れないものは住所未確定とする。

### 解釈できなかった点

1,313 件のうち 1,286 件では、パーサーが問題を検出しなかった（配布終了で場所が空の 6 件を含む）。
これは全件の解析結果が正しいと確認したという意味ではない。
問題ありとして検出したのは 27 件で、黙って捨てた行はない。
問題を検出しなかったものから、条件つきのカードを無作為に8件抜き出して確認したところ、施設名、住所、電話番号の割り当ては8件とも正しかった。

| 問題の種類 | 件数 | 主な原因 |
|---|---|---|
| 住所の後に分類できない行がある | 20 | 期間限定の配布場所の変更、休館日の代わりの配布場所 |
| 住所がない | 7 | 住所が問合せ先の欄にしかない、窓口ごとに電話が書かれ住所が1つしかない |
| 1つの場所に住所が複数ある | 6 | 期間限定や休館日の代わりの配布場所が、見出しなしで続く |
| 施設名がない | 2 | 配布開始前、一時中止で場所の記載がない |

どれも人が読んで判断すべき書き方であり、パーサーをこれ以上複雑にするより、手修正の上書きファイルで扱うほうがよい。

## 設計に反映すべきこと

- **期間限定の配布場所**：「令和8年10月19日から令和9年4月上旬まで配布場所が下記に変更」のような記載が少なくとも5件ある。曜日のような条件だけでなく、期間つきの配布場所をデータとして持てるようにする。
- **休館日の代わりの配布場所**：「休館日は下記にて配布」のような記載が少なくとも8件ある。条件として「休館日」を扱えるようにする。
- **配布開始前の状態**：「通常配布開始時に掲載します」のように、一覧には載っているが配布がまだ始まっていないカードがある（綾瀬市 B001）。要件定義の配布状態（配布中、一時中止、配布終了、不明）に当てはまらない。
- **ID の確定には画像が要る**：全カードの番号を画像の印字で確かめる必要がある。画像からの読み取り（OCR）は、蓋の座標だけでなくカード番号の確定にも使う。
- **表記の揺れ**：全角と半角、ハイフンの異体字（`‐` `－`）、康熙部首の「⻑」（U+2ED1）が混ざっている。取り込み時に正規化する。
