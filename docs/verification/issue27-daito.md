# Issue27 大東市上下水道局の棟対応調査

本書と調査JSONは担当者の提案時点の記録を含む。親の採否・適用結果・Gemini 4 Argonレビュー完了後の状態は[統合記録](issues25-27-integration.md)を参照。

2026-11-05。総務課・宿直室の2施設は位置採用を保留した。同住所を理由に同じ座標を共有してはいけない根拠が、既存の公式配布本文にあった。対象ID・停止再開条件・原典候補は[outcomes.json](../../data/national/issue27/outcomes.json)、取得UTC・hashは[retrievals.json](../../data/evidence/issue27/retrievals.json)に保存した。親とArgonの独立レビューは別途行う。

## 今回判明したこと

[市の配布ページ](https://www.city.daito.lg.jp/soshiki/39/40329.html)は、平日の配布を上下水道局庁舎2階の総務課、休日の宿直室を正門から入ってすぐ左手の建物と説明する。この記述はIssue7保存原本にも存在し、今回のサイト更新で追加された情報ではない。同棟を立証できないため共有を止めるが、この本文だけで宿直室の正確な外形や「別館」との同一性を断定してはいない。

[個別施設計画の行政系抜粋](https://www.city.daito.lg.jp/uploaded/attachment/19736.pdf)を新規取得し、物理14ページ・紙面4-1-14を画像確認した。局には管理棟、別館、渡り廊下が記載される。[発電設備記事](https://www.city.daito.lg.jp/soshiki/39/23887.html)は局庁舎を灰塚配水場管理棟と呼ぶ。複数棟の存在は分かるが、宿直室がどの棟かはこの資料から分からない。

旧原本の15499.docxは、保存拡張子が.htmlでも実体はOffice Open XML Wordだった。XML、埋込EMF、外部リンク関係を解析し、LibreOffice 26.8.0.3でPDF化、PNG化して確認した。局・市役所・駅・交差点を結ぶ概略アクセス図で、局の正確な外形や宿直棟は描かれていない。添付が市役所だけの無関係な図というわけではなかったが、概略記号の中心を建物代表点に使うこともできない。[解析記録](../../data/evidence/issue27/docx-analysis.json)に原本・生成画像hashを残した。変換時のshape/EMF警告と一部文字の重なりがあり、元Wordでの表示を完全再現したとは扱わない。

## 数値候補と保留理由

[公式施設地図303](https://www.city.daito.lg.jp/map/303.html)から34.702918, 135.614634を特定した。補助JSはこの値を地図のcenterとmarker.positionの双方へ渡すので、単なる表示中心ではない。ただし、原典には測地系、測量・作成方法、棟の精度が明記されていない。Google APIへ渡す実装は、数値がGoogle由来であるとの証明にも、座標の利用条件確認にもならない。

GSI標準地図z18の外形と比較すると、候補は細長い外形内に入るように見える。しかし、その外形が管理棟・別館・宿直建物のどれかを確認できず、GSI地物の整備年月も不明。建物代表点で足りるという方針は維持し、入口精度を新しい採用要件にはしていない。

[市の一般著作権案内](https://www.city.daito.lg.jp/site/userguide/1014.html)は確認したが、個別markerの由来・利用条件までは確定できなかった。一般規約だけで数値の利用を一律禁止とは判断せず、棟対応・CRSの不足と分けて保留する。GSI標準図から保存座標を作る場合も、[タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)のリアルタイム表示向け条件だけで申請不要とは判断していない。

## 停止と再開

2施設とも採用候補updatesは0件。同じDOCX、配布HTML、markerの再取得を繰り返しても棟対応は埋まらないため停止する。

再開には、管理棟と宿直建物を区別できる敷地配置図、施設GIS、現況写真等を得て、地理参照した外形または直接座標に接続する必要がある。座標候補を得た後にCRS・加工・精度・個別利用条件を確認し、独立レビューへ提出する。原本全文の再配布と座標の利用条件は別に確認する。自治体への連絡は今回行っていない。

取得原本hash、DOCX/レンダリングhash、JSON pointer、2施設の被覆、updates空を検査した。位置・台帳・manifest・配布関係・アプリコードは変更していないため、この調査だけを理由にアプリ全体のテストは追加していない。現地・個別座標の許諾確定・独立レビューは未実施。
