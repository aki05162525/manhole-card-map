## 証拠と追跡

- [選定](../../data/national/location-batch1/kinki-selection.json)に10施設ID、初ピン対象カード、原調査参照を保持。
- [結果](../../data/national/location-batch1/kinki-outcomes.json)に各施設の取得URL・時刻・raw path・SHA-256・版・加工・条件・停止/再開条件を記録。
- [大阪候補](../../data/evidence/location-batch1/kinki/osaka-candidate.json)と[スワン候補](../../data/evidence/location-batch1/kinki/swan-candidate.json)は数値原典と独立比較の詳細。
- [取得記録](../../data/evidence/location-batch1/kinki/retrievals.json)は失敗を含む60件。取得できた47記録について原本とのSHA-256一致を確認。大阪のCC-BY CSVだけ証拠ディレクトリにも原本を収録し、その他の新原本は許諾を推定せずignored `data/work/` に保持した。再検証はURLからの再取得とhash照合が必要。

調査の実測は888.176秒（地域共通の取得待ち、画像閲覧、共通資料読解を含む）。施設別の専有時間は計測していないため、各行の時間は同一の地域区間であり足し合わせない。

Google検索結果の数値・埋め込み地図の中心は採用していない。地理院標準ラスターは原典点と建物外形の比較に使い、そこから今回新規座標を抽出していない。原本の細かな小数桁を現地測量精度とみなさない。配布関係・在庫と位置は別判断。

京都の施設データにはタイムアウト、大阪運営者アクセスHTMLには429があった。大阪は公式サイトが参照する実際のアクセス図・構内図を取得して実見した。大阪市CSVのTLSでは弱いDH交換設定に対応したが証明書検証は維持した。これらは取得記録に残した。数値原典のない施設や未確認のCRSを、推測によって採用していない。

今回の変更は調査成果のみ。10施設IDの一致・重複なしと保存原本hashを検査した。アプリ全体のテストは実施しておらず、採用後の統合検査は親担当。コードと文書の動作上の食い違いはこの担当範囲では発見していない。旧レビューの保留記録は当時の判断として残し、新資料との差分を上に記した。
