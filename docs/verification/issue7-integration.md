# Issue 7: 建物代表点による配布施設の位置補完

固定対象810施設を地域分担で追加調査し、原調査と独立レビューを分離した。198施設の位置を採用、612施設は未採用として調査履歴・不足根拠・次の資料を保持する。原調査候補202件のうち6件は独立レビューで保留、原残件だった桜木町・秦野の2件は追加確認で採用した。残件の全リンク・公開GIS・建物外形を調査し尽くしたという意味ではない。

位置は訪問先建物の代表点であり、入口・室内窓口の測量位置ではない。桜木町は名称・住所・電話、公式配置図と駅棟への対応を確認した施設固有点を採用。駅外形から約5.44m外側で、実窓口とは東西が異なる限界を記録した。建物代表用途と入口への経路終点を区別する。

住所・電話は独立レビュー済み8フィールドを訂正した。沼津水道部庁舎2窓口の住所、本部町の県名誤字、旧柚木家・児島駅の混在住所電話4件、新倉敷の電話1件。配布状態・カードと施設の関係は変更していない。座標追加は配布再開・在庫保証を意味しない。
