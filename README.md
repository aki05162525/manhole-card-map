# manhole-card-map

マンホールカードの配布施設を探し、受け取り後に蓋を訪れるための地図。React + MapLibreで一覧・検索・詳細とオフライン保存を提供する。位置未確定の施設も一覧で確認できる。

- [起動・生成・検証](web/README.md)
- [配布情報と採用基準](docs/distribution-design.md)
- [全国台帳の統合](docs/national-assembly.md)
- [開発指針](AGENTS.md)・[レビュー](REVIEW.md)

公開範囲はローカル確認とCI検査まで。現在の件数は台帳・生成物の監査から取得する。完了済みの調査や検証結果はGit履歴・PR・CIを参照する。
